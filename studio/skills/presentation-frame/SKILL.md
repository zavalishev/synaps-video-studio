# presentation-frame — ролик в рамке

## Карточка

**Зачем**: упаковка под площадку — окно приложения/браузера, «экран ноутбука», телефон,
постоянный заголовок, полоса прогресса, сегменты шагов, виньетка. Необязательно.

**API** (`@studio/presentation-frame`): `Screen` (кадр в кадре: дети видят свой размер),
`Backdrop`, `WindowCard` (mac/browser/none, наклон ≤ ±10°), `Laptop`, `Phone`, `Headline`
(постоянный заголовок 1–2 строки), `ProgressBar`, `StepDots`, `Vignette`.

**Правила**:
- Рамка съедает площадь кадра — брать, когда работает на смысл (демо интерфейса, «вот что
  получилось», серия с узнаваемой упаковкой), а не по умолчанию.
- Внутренняя сцена проходит те же проверки (Stage/FrameAudit внутри Screen).
- Без чужих логотипов и узнаваемых устройств.

**Ловушки**: мелкий текст внутри окна на телефоне не читается — крупнее или наезд; постоянный
заголовок + рамка + подписи = герой мелкий (`hero-small`).

## Подробности (читать по нужде: `studio skill presentation-frame --section <раздел>`)

Рамка говорит зрителю «это настоящий продукт / экран» (ref3: окно приложения на бежевом;
ref1: снято с экрана ноутбука, сверху неподвижный заголовок; ref2: карточка с полосой
прогресса). Она съедает площадь кадра — берите её, когда это работает на смысл (демо
интерфейса, «посмотри, что получилось», серия с узнаваемой упаковкой), а не по умолчанию.

## Что есть (`@studio/presentation-frame`, `studio/lib/presentation-frame/index.tsx`)

| Компонент | Что делает |
|---|---|
| `<Screen w h box from>` | «кадр в кадре»: дети видят свой размер `w×h` в `useVideoConfig` (Stage, Guarded, CoverImage работают как в полном кадре), снаружи вписаны в `box`. `from` — сдвиг времени внутреннего ролика |
| `<Backdrop color blobs dots drift>` | подложка: заливка (`color` обязателен — из theme.palette), по желанию пятна (медленный дрейф) и точечная сетка; по умолчанию без них |
| `<WindowCard box chrome title url tilt dark content>` | окно: `mac` (три точки + название), `browser` (адресная строка), `none`; наклон ≤ ±10° |
| `<Laptop box content tilt glow>` | обобщённый ноутбук (без логотипов), экран 16:10, блик стекла, свет экрана на «стол» |
| `<Phone box content tilt>` | обобщённый телефон, внутри кадр 1080×1920 |
| `<Headline text box font accent maxLines>` | постоянный заголовок 1–2 строки; кегль считается один раз (ширина не «дышит»); акцентное слово другим цветом/шрифтом |
| `<ProgressBar box color value>` | тонкая полоса прогресса (по умолчанию — доля ролика); `color` обязателен — из theme.palette |
| `<StepDots count done current color>` | сегменты шагов; `color` обязателен |
| `<Vignette strength>` | виньетка |

## Как

Сцена, написанная для 1080×1080, в окне браузера на подложке:

```tsx
import { Backdrop, Headline, ProgressBar, WindowCard } from "@studio/presentation-frame";
import theme from "../theme.json";
const P = theme.palette;                 // все цвета рамки — из арт-дирекции ролика

<Backdrop color={P.bg}>
  <Headline text="Ночь на маяке — одной фразой" box={{ x: W * .08, y: H * .1, w: W * .84, h: H * .13 }}
    font={sans} weight={800} color={P.ink} accent={{ word: "одной фразой", color: P.accent, font: serif }} />
  <WindowCard box={{ x: W * .07, y: H * .3, w: W * .86, h: W * .86 + 58 }} chrome="browser" url="studio.local/scene-03"
    font={sans} tilt={{ y: -4, x: 2 }} content={{ w: 1080, h: 1080 }}>
    <NightScene />                       {/* useVideoConfig внутри = 1080×1080 */}
  </WindowCard>
  <ProgressBar box={{ x: W * .07, y: H * .76, w: W * .86, h: 10 }} color={P.accent} />
</Backdrop>
```

«Снято с экрана» — тёмная комната, ноутбук, заголовок сверху:

```tsx
<AbsoluteFill style={{ background: "radial-gradient(90% 60% at 50% 55%, #2a2733, #121016 75%)" }}>
  <Headline text="Ролик целиком — из одного брифа" box={…} font={serif} italic color={P.onDark ?? P.bg} />
  <Laptop box={{ x: W * .04, y: H * .36, w: W * .92, h: H * .4 }} content={{ w: 1600, h: 1000 }} tilt={{ x: 6 }} glow={1}>
    <Scene />
  </Laptop>
  <Vignette strength={0.5} />
</AbsoluteFill>
```

Готовый ролик в рамке (второй проход): `<Screen w={1080} h={1920}><OffthreadVideo src={staticFile("main.mp4")} /></Screen>`
внутри `Phone`/`WindowCard`; длину рамочной композиции — по длине ролика.

## Стартовые точки (необязательно)

- Окно на подложке (ref3/ref4): подложка `#efe6d8`–`#f4efe6`, пятна персик + голубой,
  точечная сетка 10 % чернил, радиус окна ~3.5 % стороны, мягкая двойная тень, наклон 2–4°.
- «Снято с экрана» (ref1): тёмная комната, заголовок 2 строки курсивной антиквой, виньетка 0.5.
- Карточка с прогрессом (ref2): тёмный фон, полоса прогресса яркого акцента внизу карточки.
- Квадрат 1:1 для ленты — `job.json` 1080×1080; рамка тогда занимает больше площади.

## Чеклист

- [ ] Рамка мотивирована (демо, серия, «как в приложении»); иначе — без неё.
- [ ] Заголовок читается на телефоне: ≤ 2 строк, кегль ≥ 3.5 % высоты кадра, контраст ≥ 4.5.
- [ ] Главное внутри рамки крупно: внутренний кадр не мельче ~60 % ширины внешнего.
- [ ] Наклон ≤ ±10°, без анимации наклона быстрее лимита камеры (рамка — тоже «камера»).
- [ ] Никаких чужих логотипов/брендов на устройствах и в адресной строке.
- [ ] Внутри рамки — свои проверки сцены (страховка работает в размере внутреннего кадра).
