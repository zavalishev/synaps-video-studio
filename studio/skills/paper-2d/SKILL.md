# paper-2d — тёплый ручной мир из бумаги

## Карточка

**Зачем**: бумага, коллаж, аппликация в SVG — рваные листы, волны со строчкой, подвесы, куклы,
значки, декорации; тёплый ручной стиль, сказка, дешёвый рендер (замена 3D).

**API** (`@studio/paper-2d`): `PaperScene` (фильтры бумаги), `TornShape`, `PaperCircle`,
`PaperLabel`, `StitchedWave`, `Hanging` + `PaperStar`, `Bob`, `Beam`, `Stars`, `PaperPuppet`
(эмоции, жесты, шаги), `PaperProp`, `PaperSet` (city/island/stall/board), `paperTheme(theme)`, `PAPER_LOOKS`,
`useTextWidth`; игра героя — `fall`, `hop`, `squash`, `anticipate`, `wobble` из `@studio`.

**Правила**:
- Сцена — слои (даль, средний план, герой, передний), глубина — тень между слоями, зерно,
  неровный край; жизнь — покачивание слоёв в разных фазах.
- Игра героя — законы мультипликации, слой `data-acting`: падение с ускорением, сжатие при
  приземлении, замах перед прыжком. «Холодно» = дрожь всем телом (`data-acting`) + сдвиг цвета
  в холод + облачко дыхания — проверки это принимают.
- Обещанная фактура (рваный край, зерно) — на КАЖДОМ плане, не только на листе стиля:
  облака из контурных кругов — не бумага. Герой и крупные формы — с рваным краем или видимой
  слоистостью вырезок (`TornShape`/`circleTorn` силуэтом, фильтр `#edge`, тень между слоями),
  а не `#grain` поверх гладких кривых: на плитке 270 px гладкий вектор читается «флэш-мультиком».
  Выбрал плоский вектор — так и напиши в concept.md.
- Герой внутри svg-сцены — `<g data-hero>`: review меряет его размер, срез краем, направление
  на склейках (`hero-cut`, `mirror-cut`).

**Показ действия** (упражнение, жест): ключевая поза работает **силуэтом** на плитке 270 px —
голова и направление движения видны в контуре, стрелка совпадает с движением; тело не
проходит сквозь реквизит (стул, стол), если это не задумано; «проблема» и «решение» выглядят
по-разному. Знаки героя (`theme.hero.marks`: хвост, повязка) — в каждом бите. Стрелки,
которые рисуются, — `drawOn` из `@studio/explainer-cards` (иначе точка на старте).

**Ловушки**: смена тепло/холод через `mix` синего и оранжевого даёт серо-хаки — `mixOk` (OKLCH);
нижние 30–40 % кадра «полосами воды» — пустая полоса (review `top-heavy`/`sparse`):
опусти горизонт или наедь камерой.

## Подробности (читать по нужде: `studio skill paper-2d --section <раздел>`)

Бумажная сцена — это **слои**: дальний фон, средний план, герои, передний план. Глубину
дают тень между слоями, зерно и неровный край, а жизнь — медленное покачивание слоёв в
разных фазах (ref1: море со строчкой, звёзды на нитках, маяк). Всё рисуется SVG-примитивами,
рендер — секунды, стоимость — ноль.

## Когда брать

- Сказка, детская тема, «уютный» малый бизнес, ностальгия, ручная работа.
- Нужна сцена с героем, а платные картинки не окупаются (или как ступень лестницы отказа:
  3D → 2.5D → **2D бумага**).
- Хорошо сочетается с generated-imagery в стиле `papercut`: сгенерированный герой-вырезка в
  бумажной сцене.
- Не брать: интерфейсы и данные (explainer-cards, data-viz), фотореализм.

## Что есть (`import … from "@studio/paper-2d"`)

| Примитив | Что рисует | Жизнь от кадра |
|---|---|---|
| `PaperScene` | корень-SVG: фильтры бумаги `#shadow #shadow-soft #grain #edge`, палитра набора | `viewBox="frame"` (px кадра) или `"kit"` (1080×1920 набора) |
| `TornShape` / `PaperCircle` | рваный лист / рваный круг (луна, солнце, монета) | — |
| `PaperLabel` | надпись на рваной полоске; ширина — замер настоящим шрифтом | — |
| `StitchedWave` | полоса моря с белой строчкой | покачивание `sway` px, период `period` с, своя фаза |
| `Hanging` + `PaperStar` | подвес на нитке, маятник ≤ 6°, «спуск» на нитке | `drop: {at, dur}`, `amp`, `period`, `decay` |
| `Bob` | покачивание на воде (вверх-вниз + наклон) | `lift`, `tilt`, `period` |
| `Beam` | луч маяка/фонаря: градиент, screen, размытие | медленный поворот (или `angle(f)`) |
| `Stars` | рассыпь звёзд по сиду, плавное мерцание | — |
| `PaperPuppet` | бумажная кукла набора: тело-лист/чек/ценник, лицо 7 эмоций, жесты, шаги | `walk: {to, start, end}`, `talk` 0..1, `energy` |
| `PaperProp` | значки набора: coin, coins, fish, boat, house, bank, car, crown, question, bulb, cross, heart, arrow-up/down, chest | — |
| `PaperSet` | декорации набора: city, island, stall, board (в `viewBox="kit"`) | `ambient` — скорость жизни (окна, машины, облака) |
| `useTextWidth` | ширина строки настоящим шрифтом (кадр ждёт замер) | один замер на текст |

Всё остальное из набора — напрямую из `@studio/paper-kit/kit/…` (Items, geometry, paper); набор
рассчитан на 1080×1920.

## Как

```tsx
import * as Unbounded from "@remotion/google-fonts/Unbounded";
import { useCyrillicFont } from "@studio";
import { PAPER_LOOKS, paperTheme, PaperScene, PaperCircle, Stars, Hanging, PaperStar, StitchedWave, Bob, PaperProp, Beam, PaperLabel, mix } from "@studio/paper-2d";

import theme from "../theme.json";
const { palette: pal, look } = paperTheme(theme, PAPER_LOOKS.soft); // роли палитры — из theme.json
const font = useCyrillicFont(Unbounded, { weights: ["800"] });

<PaperScene palette={pal} look={look}>
  <rect x={-40} y={-40} width={W + 80} height={H + 80} fill={pal.bg} />            {/* задник шире кадра */}
  <Stars n={46} box={{ x: 0, y: 60, w: W, h: 900 }} fill={pal.paper} seed={4} />
  <PaperCircle cx={790} cy={430} r={120} fill={pal.highlight} seed={9} />
  <Hanging x={330} y={-10} length={250} amp={4} period={3.4} drop={{ at: 12, dur: 26 }} thread="rgba(243,234,216,.55)">
    <PaperStar r={38} fill={pal.highlight} />
  </Hanging>
  <Beam x={200} y={733} length={980} spread={14} opacity={0.55} />
  <StitchedWave y={1150} fill={mix(pal.bg, "#3a6ea5", 0.55)} amp={16} wavelength={300} phase={0.2} sway={12} period={6} stitch="rgba(255,255,255,.75)" />
  <Bob x={640} y={1205} lift={9} tilt={3.5} period={3.4}><PaperProp name="boat" x={0} y={-40} palette={pal} /></Bob>
  <StitchedWave y={1270} fill={mix(pal.bg, "#2f5d8f", 0.7)} amp={20} wavelength={340} phase={1.4} sway={16} period={5.2} stitch="rgba(255,255,255,.7)" />
  <PaperLabel x={W / 2} y={H * 0.7} text="ТИХАЯ ГАВАНЬ" font={font} size={60} fill={pal.paper} ink={pal.ink} rotate={-2} />
</PaperScene>

// Кукла и декорация набора — в координатах 1080×1920:
<PaperScene palette={pal} look={look} viewBox="kit">
  <PaperSet set="city" palette={pal} ambient={1} />
  <PaperPuppet x={260} y={1450} scale={0.95} palette={pal} walk={{ to: 470, start: 4, end: 50 }} mood="happy" gesture="wave" talk={talk} look="receipt" mark="cap" />
</PaperScene>
```

`talk` — громкость реплики 0..1: возьмите окно слова из words.json (`useWords`, `wordAt`) и
открывайте рот на звучащих словах. Эмоции куклы: neutral, happy, proud, sad, worried,
shocked, thinking; жесты: idle, wave, point, hold, shrug, cheer.

Свой бумажный объект (маяк, дом, дерево) — обычные `<path>` с `filter="url(#grain)"` внутри
`<g filter="url(#shadow)">`; рваный край — `tornRect(w, h, seed, amp)` или фильтр `#edge`.

## Игра героя — не скольжение курсора

Кукла, которая плывёт по твину, читается как «движущаяся страница книжки». Детская
анимация живёт игрой (в стоящем кадре, слой с `data-acting`):
- падение — с ускорением (`fall` из `@studio`), капля не тормозит в воздухе;
- приземление — сжатие и затухающая упругость (`squash`), прыжок — замах (`anticipate`) и
  парабола (`hop`), после толчка — покачивание (`wobble`), в падении — вытягивание
  (`stretchBySpeed`);
- эмоция героя на развязке — та, что в тексте (волнуется ≠ сердится);
- выход героя из кадра и вход на следующем плане (улетела вверх — влетела снизу) —
  `data-bleed`, движение продолжается через склейку (transitions).
Лимиты «спокойного кадра» — для камеры и фона; игра персонажа — по законам мультипликации.

## Палитра и фактура

Палитра — только `paperTheme(theme)`: роли набора (paper, highlight, positive, negative)
выводятся из `theme.palette`, своё значение роли — одноимённым ключом в palette. Готовых
палитр («ночное море», «крафт», «пастель») больше нет — они становились домом студии.
Фактура без цвета — `PAPER_LOOKS.soft | rough | clean`: `grain` 0.15–0.3, `edge` 0.3–0.5, `shadow: "soft"`.
Темп жизни: волны 5–7 с на период, `sway` 10–20 px; маятник 3–4 с, `amp` 3–5°; лодка 3–3.5 с.
Разные периоды и фазы у соседних слоёв — «живое», одинаковые — «механическое».

## Подводные камни

- Края: всё, что касается края кадра (небо, море, земля), должно быть шире кадра на свою
  амплитуду движения — `StitchedWave` делает это сам, свои слои — `x={-40} width={W+80}`.
- Ровная однотонная полоса у края кадра (земля, нижняя волна без строчки) может дать
  ложный `cover-gap` в `studio probe` — его эвристика ищет «пустую полосу» у края. Но
  сначала спросите: зачем кадру эта полоса? Треть экрана моря или холмов без действия —
  мелкий герой на телефоне. Лучше перекомпоновать (ниже горизонт, крупнее герой, камера
  ближе), чем досыпать в полосу волн и облачков.
- Предметы набора, которые сами ездят (машины в `city` при `ambient > 0`), пересекают край —
  probe скажет `edge-crossing`; это осознанная жизнь декорации, но проверьте, что внимание
  не уходит с героя (иначе `ambient={0}`).
- Кукла рассчитана на `viewBox="kit"`; в кадре другого размера сцена `kit` вписывается с
  обрезкой — держите героя в центральной части 1080×1920.
- Маятник > 6°, sway > 40 px — пишется в guard.json (`paper-swing`, `paper-sway`): читается
  как «уезжает».
- Подпись на полоске — кегль ≥ 3.5 % высоты кадра, ≤ 7 слов; шрифт с кириллицей
  (голос — из theme.json; `studio fonts --suggest hand-marker|heavy-grotesk`).

## Чеклист

- [ ] Ни один слой не открывает пустой край ни в одном кадре (смотрите крайние фазы sway).
- [ ] Куклы и предметы стоят на линии пола/воды, а не висят над ней (кроме подвесов).
- [ ] Герой играет (падение с ускорением, приземление, эмоция по тексту), а не скользит по твину;
      на плитке телефона он крупный, полосы декора не занимают треть кадра без дела.
- [ ] Покачивание слоёв не синхронно (разные фазы и периоды), но и не хаотично.
- [ ] Тени у всех слоёв в одну сторону; фактура одинаковая во всей сцене (один `look`).
- [ ] Текст на полоске читается, полоска шире текста (замер шрифтом).
- [ ] probe: без fast-motion/shake; `cover-gap`/`edge-crossing` — разобраны глазами и записаны.

## Проверено

Проверочный ролик — «Тихая гавань» (луна, звёзды на нитках спускаются, маяк с
лучом, четыре слоя волн со строчкой, лодка на волнах, надпись на полоске) и ночной город
набора с куклой, которая идёт, машет и говорит, монеты на нитках. Кадры:
`out/stills/f0090.png` (море, лучший кадр), `out/stills/f0170.png` (город). probe: скорость
0.17 %W/кадр макс.; два FAIL эвристики разобраны: `cover-gap` снизу — однотонная нижняя
волна (кадр в порядке), `edge-crossing` слева — машина декорации въезжает в кадр.
