# data-viz — цифры, которые читаются за секунду

## Карточка

**Зачем**: одно утверждение с цифрой, которое читается за 2–4 с: счётчик, столбики, линия, кольцо,
бублик, пиктограмма «k из n».

**API** (`@studio/data-viz`): `Counter` (табличные цифры, `step` — промежуточные значения
круглым шагом, в конце точное число), `countAt`, `niceStep`, `BarChart` (`orientation="row"`
для 9:16), `LineChart` (`markers`, `endLabel`), `Ring`, `Donut` + `Legend`, `Pictogram`,
`SourceNote`, `fmtNum`, `fitLabelPx`, `vizTheme(theme, {font})` (тема графика только из theme.json).

**Правила**:
- Цифра — герой: ключевое число 50–70 % ширины кадра (не 70 px в углу карточки).
- Число появляется на слове (±2 кадра), досчитывает за 0.6–1 с, держится ≥ 1 с; в речи и на
  экране — дословно одинаковое.
- ≤ 5 категорий; таблица на телефоне — последний вариант (≤ 3 столбца, одна мысль на строку).
- Герой-визуал развязки (разрыв, пик, разница) — крупно: наезд или отдельный план, `data-hero`.

- Счётчик, продолжающий число прошлого бита, начинается с этого же числа на склейке
  (`from` = конец прошлого бита; countAt держит from ровно и не идёт назад).
- **Перегруппировка — это доказательство**: переход между состояниями данных показывай
  движением частей (полоски «процент на процент» съезжаются в шапку, доли складываются в
  итог) за 20–40 кадров, а не склейкой на готовое; одна шкала мира на все биты, крупность —
  камерой (`PushIn`/`frameSubject2D`), а не новым k на склейке.
- График без чисел на осях несёт короткую подпись «что это» (`проценты за каждый год`);
  вывод бита — размером предложения, не подписи. Подпись в узкой плашке — `fitLabelPx`
  (review `text-clipped`).

**Ловушки**: «мусорные» промежуточные суммы (138 019 ₽) — оставь `step` по умолчанию; подпись
≥ 1.8 % высоты (`viz-label-small`); рост столбиков быстрее 20 кадров — «прыгает».

## Подробности (читать по нужде: `studio skill data-viz --section <раздел>`)

Зритель вертикального ролика видит график 2–4 секунды. Задача — не «показать данные», а
сделать **одно утверждение** с цифрой: «выручка выросла на 38 %», «раф — половина заказов»,
«7 из 10 возвращаются». Форма графика выбирается под это утверждение.

## Когда брать

- В речи есть число, рост/падение, сравнение, доля, прогноз, рейтинг.
- Цифра — главный аргумент бита (обычно hook или punch).
- Не брать: число одно и без сравнения — хватит крупной цифры из kinetic-typography; данных
  больше 5 категорий — сначала сократите (объедините в «прочее») или разбейте на два кадра.

## Что выбрать (подсказка, не правило)

| Утверждение | Форма | Компонент |
|---|---|---|
| «стало N» / «+38 %» | крупная цифра со счётом | `Counter` |
| «A больше B», рейтинг до 5 | столбики, один выделен | `BarChart highlight` |
| длинные подписи / вертикальный кадр | горизонтальные полосы | `BarChart orientation="row"` |
| динамика во времени | линия с заливкой, точка-голова, метка события | `LineChart area markers` |
| доля одного целого | кольцо с цифрой в центре | `Ring` + `Counter` |
| структура (≤ 5 частей) | бублик + легенда | `Donut` + `Legend` |
| «k из n людей» | сетка иконок | `Pictogram` |
| 3D-столбики | см. скиллы three-d (InstancedMesh, высота от кадра) | — |

## Как

```tsx
import * as Display from "@remotion/google-fonts/<fonts.display.module>"; // из theme.json
import { useCyrillicFont, Guarded } from "@studio";
import { zones } from "@studio/layout-guard";
import { BarChart, Counter, LineChart, Ring, Donut, Legend, Pictogram, SourceNote, fmtNum, vizTheme } from "@studio/data-viz";
import theme from "../theme.json";

const font = useCyrillicFont(Display, { weights: ["500", "800"] });
const t = vizTheme(theme, { font });            // цвета — только из арт-дирекции ролика
const S = zones(W, H, undefined, { theme }).heroMax; // размеры — доли зоны героя, а не пиксели

// Счётчик: ширина не «дышит» (табличные цифры + место под итог), ru-RU формат.
<Counter value={38} from={0} start={10} dur={45} prefix="+" suffix=" %" style={{ fontFamily: font, fontWeight: 800, fontSize: S.w * 0.22, color: t.accent }} />

// Столбики от нуля, рост по очереди, подпись значения считает тем же ходом, что и высота.
<Guarded id="bars" box={S}>
  <BarChart id="drinks" theme={t} width={S.w} height={S.h} start={8} dur={26} stagger={6} highlight="Раф" suffix=" %"
    data={[{ label: "Капучино", value: 24 }, { label: "Раф", value: 41 }, { label: "Латте", value: 19 }]} />
</Guarded>

// Линия рисуется по длине, заливка открывается за ней, метка события появляется, когда линия дошла.
<LineChart data={[410, 440, 430, 480, 520, 545, 566]} width={S.w} height={S.h * 0.8} theme={t} start={14} dur={70}
  area endLabel="566 тыс. ₽" xLabels={["апрель", "июль", "октябрь"]} markers={[{ index: 3, label: "новое меню" }]} />

<Ring value={0.72} size={Math.min(S.w, S.h) * 0.85} theme={t} start={10} dur={40}>
  <Counter value={72} suffix="%" align="center" style={{ fontFamily: font, fontWeight: 800, fontSize: Math.min(S.w, S.h) * 0.22 }} />
</Ring>
<Donut segments={[{ label: "Зёрна", value: 46 }, { label: "Аренда", value: 28 }]} size={Math.min(S.w, S.h) * 0.85} theme={t} />
<Pictogram total={10} value={7} cols={5} size={S.w / 6} theme={t} start={46} stagger={3} />
<SourceNote text="Источник: касса, апрель–октябрь" theme={t} />
```

Чистые функции для своих графиков: `countAt(frame, {start, dur, from, to})`, `fmtNum(n,
{decimals, prefix, suffix, compact, sign})`, `fitLabelPx(text, want, slotPx)`. Свои формы —
напрямую на `d3-scale`/`d3-shape` + `evolvePath` из `@remotion/paths`; правило одно:
каждое значение — функция кадра.

Ритм: число из речи появляется **на слове** (start = кадр слова из words.json, ±2 кадра),
досчитывает за 0.8–1.5 с и **держится на экране ≥ 1 с** после досчёта. Рост столбиков —
20–30 кадров, шаг между столбиками 4–8 кадров; быстрее — «прыгает».

## Таблица на телефоне — последний вариант

- Сначала: оставить объясняющий визуал и сменить его смысл (тот же график — пунктиром как
  прогноз, минус виден заранее). Совет показывается тем же языком, что и проблема.
- Если таблица: одна мысль на строку, заголовок или единицы у столбцов, зазор между
  столбцами ≥ полсимвола, ≤ 3 столбцов на 9:16, кегль размером подписи.
- Герой-визуал развязки (зона разрыва, пик, разница) — крупно: наезд к нему или кадр, где он
  главный; review меряет долю кадра у `data-hero`.

## Цвета и размеры — из ролика

Готовых палитр нет: `vizTheme(theme, {font})` строит тему графика из `theme.palette` (muted,
сетка, дорожка, ряды — смесью в OKLCH; своё значение роли — ключом в palette). Размеры —
доли `zones().heroMax`: график — герой бита, а не врезка «как на веб-странице».

## Подводные камни

- Цифры в речи и на экране — **дословно одинаковые** (озвучено «почти сорок процентов» —
  на экране 38 %, а не 40 %; лучше поправьте реплику).
- Столбики — всегда с нуля (иначе разница врёт). Линия может не с нуля (`zero` по умолчанию
  выключен), если важна форма, а не масштаб; масштаб — `zero`.
- ≤ 5 категорий; больше — компонент пишет `viz-categories` в guard.json.
- Подписи графика ≥ 1.8 % высоты кадра (≈35 px на 1920) — иначе `viz-label-small`; это пол.
  Для чтения с телефона — ≥ 3 % (≈58 px): FrameAudit пишет `text-tiny` WARN на всё мельче
  (HTML-подписи; текст внутри SVG — проверяйте глазами на плитке телефона).
  Длинные подписи — `orientation="row"` или короче формулировка; `BarChart` уменьшает кегль
  всех подписей одинаково под самое длинное слово, а не обрезает.
- Атрибуция источника (`SourceNote`) — если цифры не из брифа клиента, а «из исследования».
- Цены и тарифы продукта в ролик не пишем (правило студии).
- Переход между графиками — уход одного до входа другого (без двойной экспозиции текста).

## Чеклист

- [ ] Одно утверждение на график; акцент (`highlight`/цвет accent) — на главном значении.
- [ ] Главная цифра/зона — самое крупное в кадре на своём бите (не «тонкая полоска» на телефоне).
- [ ] Вывод в том же визуальном языке, что проблема; таблица — только если без неё никак.
- [ ] Число совпадает с речью; появляется на слове; держится ≥ 1 с после досчёта.
- [ ] Ось столбиков с нуля; ≤ 5 категорий; подписи не пересекаются и не обрезаны.
- [ ] Цифры табличные, ширина строки не меняется при счёте (смотрите ленту `studio sheet --frames`).
- [ ] Рост без перелёта; probe без fast-motion; guard.json без viz-*.
- [ ] Контраст подписей ≥ 4.5 к фону (`contrast()` из @studio); источник подписан, если нужен.
