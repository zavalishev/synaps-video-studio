# kinetic-typography — живой текст и субтитры

## Карточка

**Зачем**: живой текст на кириллице — субтитры по словам, заголовок, счётчик, смена текста,
**удар без прыжка** и текст без плашки.

**API** (`@studio/kinetic-typography`): `Captions` (страницы по словам, `look`
clean/shadow/plate/outline, `plateRadius`), `Headline` (сегменты, акцент), `Counter` (табличные
цифры; промежуточные значения — круглым шагом), `Pill`, `SwapText` (сначала уход, потом приход —
без «каши» букв), `RollNumber` (прокрутка разрядов в окне), `maskReveal`, `scaleStep`,
`Flash`/`flashAt`, `holdFrames`, `typeOnImage`, `markerHighlight`; `Headline balance`; из `@studio/layout-guard` —
`zones`, `FitText`, `useFontReady`, `measureWidth`.

**Иерархия на телефоне**: самое важное (предложение, цифра, вывод) — самое крупное и
контрастное; ориентир ≥ 7 % высоты или ≥ 60 % ширины безопасной зоны; подписи 3.5–5 %.
Условие предложения («только по выходным») — информация, не сноска. Пометь смысл:
`data-role="offer|support|decor"` — review сверит размеры.

**Удар без прыжка** (кульминация — самый плотный момент): склейка на число в долю звука;
`maskReveal` вместо прозрачности; `RollNumber`; `scaleStep` 0.9 → 1 за 4 кадра; `Flash` 2–3
кадра (своя засветка/флеш-кадр — слой с `data-accent`: probe не примет его за склейку);
держать цифру ≥ 1 с. Не «opacity 0 → 1 через призрак».

**Число из брифа — факт** (цена, зарплата, дата, телефон): читается с первого кадра на экране.
`RollNumber` по умолчанию крутит только 2 младших разряда (`settle`), `from` — продолжить с
числа прошлого бита; полные обороты (`turns ≥ 1`) — для счётчика роста, не для факта
(review: `fact-unreadable`). Текст, который произносят, полностью читается к своему слову
(`wordAt` из words.json), а не к началу бита. Побуквенное появление дописывает слово за
≤ 6 кадров, вторая строка не начинается одинокой буквой. Перенос фразы по строкам сохраняет
её знаки: «ВРЕМЯ — / ГЛАВНЫЙ СОЮЗНИК», а не без тире.

**Подача (`theme.type.lockup`) — выбор, не умолчание `Headline`**. Словарь (смешивать можно):
одно начертание, узкие капслоком; блок влево рваным краем; одно слово на кадр во весь экран;
текст напечатан в мире (ценник, чек, вывеска, стикер); рукописная пометка поверх фото;
нумерованная редакционная (01 / 02); курсив-акцент — один вариант из многих, не дом студии.
`Headline balance` — строки равной длины («Спелый / мандарин.» не висит словом).

**Не всё — таблетка**: текст прямо на картинке (`typeOnImage`), маркер под словом, брусок
`plateRadius: 0`, текст «в мире» (на вывеске, бумаге, доске), слово во весь кадр. Форма — из
`theme.shapes`.

**Ловушки**: мерить ширину только после `useFontReady`; скрим a ≥ 0.8 на трети кадра — мёртвая
зона: лучше тень/локальная подложка или картинка с местом под заголовок; акцентный цвет на
картинке — самый слабый по контрасту (review `contrast-px`).

## Подробности (читать по нужде: `studio skill kinetic-typography --section <раздел>`)

Текст в кадре — часть режиссуры: что подсвечено, то зритель запомнит. Компоненты дают
стабильную раскладку (ширина не «дышит», соседние слова не сдвигаются), Cyrillic-шрифты,
безопасную зону и проверки; вид, кегль, ритм и что выделять — решает директор.

## Когда брать / когда нет

- Субтитры: почти всегда, когда есть речь (ролики смотрят без звука). Не нужны, если в кадре
  уже крупно написано то же самое (заголовок-крючок) — не дублируйте текст: подписи можно
  начать со следующего бита (см. пример ниже).
- Заголовок: крючок, перебивка раздела, вывод. Счётчик: цифра из речи. Плашка: статус, метка.
- Длинный текст на экране (> 7 слов одновременно) — это уже карточка (explainer-cards).

## Что даёт `@studio/kinetic-typography`

- `<Captions words font color accent onAccent keywords look zone …/>` — субтитры по словам:
  страницы по 1–4 слова (рвутся на конце фразы, паузе, запятой; служебное слово не висит в
  конце; ключевая фраза не рвётся), кегль один на весь ролик, слово загорается за кадр до звука,
  ещё не сказанные слова — призрачные (`ghost`, 0 — скрыты), звучащее — `accent`, ключевые
  фразы — плашка-шторка `accent`/`onAccent`. Вид `look`: `clean` (ровный фон), `shadow`
  (мягкая тень поверх картинки), `plate` (подложка), `outline` (обводка).
- `<Headline segments=[…, {text, accent:true}] font accentFont …/>` — заголовок из сегментов
  разными начертаниями, кегль подбирается раз под коробку, слова появляются по очереди
  (`stagger`, `wordFrames`, `rise`), уход — `exitAt`.
- `<Counter from to start dur prefix suffix font size color/>` — счёт с `tabular-nums` и
  фиксированной шириной (иначе строка дрожит — одна из причин «прыгает»).
- `<Pill text …/>` — плашка-метка со шторкой.
- `<SwapText box items={[{at, node}, …]} plate={…}/>` — текст в постоянной карточке меняется
  перекрёстно (старый уходит, пока новый приходит): нет кадра «пустая карточка»
  (FrameAudit: `empty-plate`).
- `paginate`, `pageAt`, `keywordRanges` — для своей раскладки поверх тех же правил.
- Из `@studio/layout-guard`: `zones()` (полоса подписей и заголовка под площадку),
  `FitText` (текст в коробке), `useFontReady`/`measureWidth`/`wrapWords` (свои раскладки:
  мерить только после загрузки шрифта и один раз, а не на каждом кадре).

## Как

```tsx
import * as Display from "@remotion/google-fonts/<fonts.display.module>"; // из theme.json
import { Sequence } from "remotion";
import { useCyrillicFont, useWords } from "@studio";
import { zones } from "@studio/layout-guard";
import { Captions, Counter, Headline } from "@studio/kinetic-typography";

const heavy = useCyrillicFont(Display, { weights: ["800"] });
const words = useWords();                       // public/words.json
const z = zones(W, H, "reels");                 // safe, caption, title, hero

// подача «блок влево, одно начертание, цифра цветом» (а не «вторая строка курсивом»)
<Headline id="hook" box={{ ...z.title, h: z.title.h * 0.8 }} valign="top" start={4} align="left" balance
  segments={["Аренда дороже —", { text: "а прибыль выше?", color: P.accent }]}
  font={{ family: heavy, weight: 800 }} color={P.ink} maxSize={Math.round(H * 0.07)} />

// подписи со 2-го бита (первый говорит заголовок): startFrame возвращает абсолютное время слов
<Sequence from={CAPS_FROM} layout="none">
  <Captions words={words?.words ?? []} startFrame={-CAPS_FROM} font={{ family: heavy, weight: 800 }}
    color={P.ink} accent={P.accent} onAccent={P.onAccent} keywords={["в десять раз", "без рекламы"]}
    look="clean" background={P.bg} zone={z.caption} />
</Sequence>

<Counter from={1} to={10} start={wordFrame} dur={22} prefix="×" font={{ family: heavy, weight: 800 }}
  size={Math.round(H * 0.12)} color={P.accent} />
```
Одно слово крупно (стиль «по слову»): `pages={{ maxWords: 1 }} sizeFrac={0.075} ghost={0}`.

## Иерархия на телефоне

- **Самое важное — самое крупное и самое контрастное.** Название продукта, предложение,
  главная цифра, вывод — сильнее настроенческой строки и подписи. Если крючок «Осень пришла»
  громче, чем «Тыквенный латте», иерархия перевёрнута.
- Размер ключевого текста решайте **относительно героя**, а не от минимума: «цифра — герой
  бита» значит, что в момент появления она крупнее всего остального в кадре. Минимум
  (3.5 % H) — пол читаемости, а не размер для главного.
- Акцентный цвет/курсив на картинке — самый слабый по контрасту: тёплый акцент на тёплом
  боке почти не виден. Акцент на изображении получает подложку (плашка, скрим, тень
  плотнее) или переходит в «чернила»; проверка — `contrast-px` в review (меряет по пикселям
  кадра, а не по объявленному `background`).
- Всё, что зритель должен прочесть, — размером подписи; мельче — только декор (`data-decor`).
  Подписи к схеме, метки осей, «Совет:» — это текст для чтения.

## Стартовые точки (необязательно)

- Кегль подписей 9:16 ≈ 0.05 H (мин. 0.036 H), ключевое слово бита ≥ 0.07 H, цифра-герой
  0.12–0.2 H или 50–70 % ширины.
- Подписи — в `zones().caption` (центр ≈ 84 % безопасной зоны, над интерфейсом Reels).
- Страница 2–4 слова, ≤ 24 знаков, 2 строки; удержание после речи 0.6 с.
- Появление слова 4 кадра, заголовка — 10 кадров со сдвигом 3; без пружин с перелётом.
- Шрифты и форма плашек — из theme.json (`fonts`, `shapes`), а не по привычке: голос
  шрифта подбирается под предмет брифа (`studio fonts --suggest`).
- Поверх картинки: `shadow` или `plate`; на ровном фоне: `clean`. Затемнение картинки
  градиентом под полосой подписи — дешевле, чем плашка, и сохраняет живой фон.

## Чеклист

- [ ] Кегль подписей ≥ 3.5 % высоты (useTextCheck/guard: `caption-small`), заголовка ≥ 3 %.
- [ ] Контраст ≥ 4.5 к фону/плашке (guard: `caption-contrast`) — передайте `background`
      (цвета — любой CSS, плашка с альфой проверяется по худшему случаю); по факту кадра —
      review `contrast-px`.
- [ ] Самое важное слово/цифра — самое крупное и контрастное в момент появления.
- [ ] Смена текста в постоянной плашке — `SwapText`, без кадров «пустой карточки».
- [ ] Не больше 7 слов одновременно; текст не на лице/герое и не под интерфейсом
      (FrameAudit: `text-outside-safe`, `text-cut`).
- [ ] Ключевые фразы — те, что важны по смыслу (из beats.json), 1–2 на бит, не каждое слово.
- [ ] Текст и речь не дублируют друг друга двумя блоками одновременно.
- [ ] Числа — `Counter` или `tabular-nums` (review: `el-width-jitter`, lint: `number-jitter`).
- [ ] На стопкадрах нет «квадратиков» и запасного шрифта; строки не начинаются с «—».
- [ ] Рассинхрон слова и звука ≤ 2 кадров (слово загорается за кадр до звука).
