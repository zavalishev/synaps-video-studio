# typography-3d — объёмный текст

## Карточка

**Зачем**: объёмные надписи с кириллицей — заголовок-удар, цифра-герой («−30%»), логотип-слово,
вывеска в 3D. Редко: одна-две на ролик.

**Как**: Blender читает TTF Google Fonts с кириллицей, фаска и выдавливание, `check_glyphs` ловит
«квадратики» до рендера. `text3d.letters()` → узлы `char_00…` (анимация по буквам в three
через `<AnimatedGltf>` + `stagger()`), `text3d.text3d()` — одним мешем; или PNG `--transparent`.
Пример: `examples/title.py` + `examples/Title3D.tsx`.

**Правила**: подписи и субтитры остаются 2D (kinetic-typography); материал — тот же токен, что у
мира (materials); буква растёт «из себя» (начало координат — центр низа).

**Ловушки**: TextGeometry в three требует typeface.json с кириллицей — лишняя точка отказа;
тонкие засечки при выдавливании ломаются — жирные начертания.

## Подробности (читать по нужде: `studio skill typography-3d --section <раздел>`)

Объёмная надпись — сильный акцент, поэтому редкий: одна-две на ролик, когда слово/цифра — главное
в кадре. Подписи и субтитры остаются 2D (`kinetic-typography`).

## Почему через Blender

Blender читает любой TTF с кириллицей напрямую, делает честную фаску и выдавливание, а `check_glyphs`
ловит «квадратики» до рендера. `TextGeometry` в three требует конвертировать шрифт в typeface.json
(с подмножеством кириллицы) — лишняя точка отказа; в three надпись приезжает GLB.

## Что получаешь

- `letters()` → узлы `char_00`, `char_01` … (номер = индекс символа в строке, пробелы пропущены),
  начало координат каждой буквы — центр её низа: буква растёт/поворачивается «из себя». Кернинг сохранён.
- `text3d()` → надпись одним мешем (вывеска, логотип, статичный заголовок).
- GLB + паспорт `.json` (`s3.export_glb`) → `<AnimatedGltf>` с `stagger()`; или PNG `--transparent` из Blender.

## Как (проверено: examples/title.py + examples/Title3D.tsx)

```python
import sx, text3d as t3, scene3d as s3
a = sx.args(lambda p: p.add_argument("--glb"))
sx.reset()
font = t3.font_file("Unbounded", 800)        # Google Fonts → .cache/fonts/Unbounded-800.ttf (сеть один раз)
l1 = t3.letters("СКИДКА", font, size=0.9, extrude=0.1, bevel=0.03, style="plastic", color="#e63946", prefix="char")
l2 = t3.letters("−30%", font, size=1.9, extrude=0.16, bevel=0.05, spacing=1.08, style="plastic", color="#ffb703", prefix="num")
for o in l2: o.location.z -= 2.35            # вторая строка ниже (строки — отдельными вызовами)
s3.export_glb(a.glb)
```

```tsx
const R = fitBox(meta.bbox, fov, W, H, 0.9);  // надпись широкая и плоская — кадрировать по боксу
<ThreeCanvas width={W} height={H} camera={{ fov: 24 }}>
  <Tone mode="neutral" /><StudioEnv intensity={0.35} />
  <StudioLights preset="product" target={target} scale={2} shadows={false} intensity={0.85} />
  <CameraRig position={cam.position} target={cam.target} fov={24} />
  <InFrame id="title">
    <AnimatedGltf src={staticFile("3d/title.glb")} animate={(n, f) => {
      const m = /^(char|num)_(\d+)/.exec(n.name); if (!m) return;
      const p = m[1] === "char" ? stagger(f.frame, +m[2], { start: 6, step: 3, dur: 20 })
                                : stagger(f.frame, +m[2], { start: 34, step: 4, dur: 24 });
      n.position.y = f.base.position.y - (1 - p) * 0.5;   // поднимается
      n.rotation.x = f.base.rotation.x - (1 - p) * 1.2;   // встаёт из наклона
      n.scale.setScalar(Math.max(0.001, p));              // без перелёта (EASE), без пружины
    }} />
  </InFrame>
</ThreeCanvas>
```

Шрифт: только семейства с кириллицей (`studio fonts <поиск>`); для 3D хороши широкие и жирные:
тяжёлые гротески и плакатные (`studio fonts --suggest heavy-grotesk|poster-condensed`). Тот же шрифт —
в 2D-подписях через `useCyrillicFont`, чтобы 3D и 2D говорили одним голосом.

### Стартовые пресеты (по выбору)

- Пропорции: `extrude` 0.1–0.2 × size (глубина = 2·extrude), `bevel` 0.03–0.05 × size; больше фаска — мягче, «мультяшнее».
- Вид: `plastic` (глянец, блик по фаске) или `clay` (матовый); цвета — акценты theme.json.
- Камера почти фронтально: ±10° по азимуту, 0–8° по высоте; медленный наезд 5–8 % и доворот ≤ 8° за сцену.
- Появление: шаг 2–4 кадра между буквами, длительность 18–24 кадра, поворот ≤ 70° из наклона, без перелёта.

## Подводные камни (проверено)

- Камера сбоку при глубоком выдавливании закрывает «окна» букв: «С» читалась как «О», «−» налезал на «3».
  Лечится: фронтальная камера (≤ 10°), меньше `extrude`, `spacing` 1.05–1.1 для цифр со знаками.
- `size` = высота заглавной (кегль компенсирован на 0.72); строчные ниже — проверяй кадр.
- `font_file` скачивает TTF через fonts.googleapis.com (старый User-Agent → truetype, полный набор глифов);
  без сети работает только из кэша `.cache/fonts` — скачай заранее на шаге ассетов.
- Строка — один вызов; многострочные надписи — несколько вызовов со сдвигом `location.z` (и своим `prefix`).
- Символы `−` (U+2212), `«»`, `№`, `₽` есть не во всех шрифтах — `check_glyphs` падает с их списком.
- Масштаб 0 у буквы → выставляй 0.001 (вырожденная матрица ломает нормали).
