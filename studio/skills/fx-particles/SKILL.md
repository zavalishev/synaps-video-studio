# fx-particles — атмосфера, которая не мельтешит

## Карточка

**Зачем**: атмосфера как сообщение — дождь, снег, звёзды, пыль в луче, лучи, облака, туман, всплеск,
зерно; 2D (SVG) и 3D. Всё строго от кадра и сида.

**API** (`@studio/fx`): `Rain` (`count`, `angle`, `speed`, `area`, `clipPath`, `splash`), `Snow`,
`Stars`, `Dust` (`light(x,y)` — видна только в луче), `LightBeam`, `GodRays`, `Clouds`, `Fog`,
`Burst`, `Grain`, `lightning`, **`Leaves`** (силуэт листа: maple/oval/birch, переворот, покачивание),
**`Steam`** (`source` — над чем пар: клубы светлее фона, тают); `@studio/fx/three`: `Rain3D`, `Snow3D`, `Stars3D`, `Clouds3D`;
погода из состояния — `<WeatherFx look>` (scene-state).

**Правила**:
- Частицы читаются на телефоне: контраст к фону, толще и гуще на развязке; бит-поворот
  («Это дождь!») получает больше всего энергии (плотность, скорость, звук).
- Частица — форма предмета, а не значок шрифта: лист — силуэт листа (SVG-путь, поворот,
  покачивание), пар — мягкие вытянутые клубы с размытием над источником; символы «✶» читаются
  как мусор.
- Частицы не поверх ключевого текста.

**Ловушки**: светлые тонкие штрихи дождя на светлом небе не видны с плитки; серое пятно пара на
тёмном фоне читается как грязь — пар светлее фона и только над горячим; вспышки молнии —
коротко и редко.

## Подробности (читать по нужде: `studio skill fx-particles --section <раздел>`)

Частица — не украшение, а сообщение: дождь = буря/грусть, звёзды = ночь/сказка, пыль в луче =
утро/тишина, всплеск = «да!». Плотность и скорость выбирайте под темп речи: спокойный
рассказ — редкие медленные частицы; хук — можно гуще, но не поверх текста.

Частицы должны **читаться на телефоне**: тонкие светлые штрихи дождя на светло-сером небе
с плитки 360 px не видны. Проверка — плитка `phone-sheet.png` (review) и контраст частиц к
фону (светлые частицы — на тёмном, тёмные — на светлом; толще и гуще на развязке). Бит, где
история поворачивается («Это дождь!»), получает больше всего энергии: плотность, скорость,
маленькое движение камеры и звук (sound-design: `bed.ts --kind rain-heavy`). Пар над горячим
напитком, пыль в луче — живые частицы поверх продукта вместо пара, нарисованного в картинке.

## Что есть

`@studio/fx` (`studio/lib/fx/index.tsx`, SVG поверх кадра):

| Компонент | Главные параметры (по умолчанию — стартовые) |
|---|---|
| `<Rain>` | `count` 90 (200 — ливень), `angle` 10°, `speed` 2.2 высоты/с, `length` 0.06 H, `area`, `clipPath`, `splash` (y линии брызг) |
| `<Snow>` | `count` 120, `speed` 0.16 высоты/с, `size` 7, `sway` 26 px, `wind`; три слоя глубины, ближние размыты |
| `<Stars>` | `count` 140, `twinkle` 0.4, `period` [2.2, 5] с, `sparkle` 6 % с лучами, `fadeTo` к горизонту |
| `<Dust>` | `count` 46, `drift`, `rise`, `light(x, y) → 0..1` — пыль видна только в луче |
| `<LightBeam>` | `origin`, `angle` (анимируйте `tween`), `spread`, `length`, `intensity`, `softness`, `core` |
| `<GodRays>` | веер мягких лучей из точки за кадром, медленное «дыхание» |
| `<Clouds>` | `count`, `speed` 0.008 ширины/с, `color`, `shade`, `band` |
| `<Fog>` | `density`, `band`, медленный дрейф |
| `<Burst at x y>` | короткий разлёт искр (ease-out, без отскока) — акцент на слове |
| `<Grain>` | бумажное/плёночное зерно; `every` ≥ 3 — плёнка, иначе неподвижно |
| `lightning(frame, strikes)` | множитель вспышки молнии (осторожно — см. чеклист) |

`@studio/fx/three` (внутри `ThreeCanvas`): `<Rain3D>`, `<Snow3D>`, `<Stars3D>`, `<Clouds3D>` —
объём частиц (`center`, `size`), `opacity` можно плавно менять (частица всегда в дереве).

Зашито в код (страховка, не стиль): положение — функция кадра и сида (`random` из remotion,
`noise2D`); перенос по модулю — **за краем области** (ничего не телепортируется в кадре);
скорость — в долях высоты в секунду (не зависит от fps и размера); размеры от `min(W,H)/1080`.

## Как

Дождь только в окне (как в ref1 «маяк»): ночь и дождь внутри стекла, комната сухая.

```tsx
const win = { x: W * 0.17, y: H * 0.16, w: W * 0.66, h: H * 0.44 };
<div style={{ position: "absolute", left: win.x, top: win.y, width: win.w, height: win.h, overflow: "hidden", borderRadius: r }}>
  <Sky look={resolveLook({ time: "night", weather: "rain" })} />    {/* из scene-state */}
</div>
<Rain area={win} clipPath={`inset(0 round ${r}px)`} count={150} angle={8} speed={1.8} splash={win.h * 0.97} />
{/* переплёт окна рисуется ПОВЕРХ дождя */}
```

Луч маяка с медленной развёрткой (40° за 6 с — спокойно; быстрее — конец луча «бежит»):

```tsx
<LightBeam origin={lamp} angle={tween(frame, [[0, -28], [179, 12]])} spread={16} length={1} intensity={0.55} />
```

Пыль в солнечном луче (видна только в свете — как в жизни, на тёмном фоне):

```tsx
const origin = { x: -W * 0.05, y: H * 0.12 }, dir = 38;
const light = (x: number, y: number) => Math.max(0, 1 - Math.abs(Math.atan2(y - origin.y, x - origin.x) * 180 / Math.PI - dir) / 13);
<GodRays origin={origin} angle={dir} fan={14} rays={4} intensity={0.55} />
<Dust count={110} light={light} size={8} />
```

Погода из состояния сцены — `<WeatherFx look>` из scene-state (дождь/снег/туман по `look`).

## Стартовые точки (необязательно)

- Сказка/ночь: `Stars` 100–150, `twinkle` 0.3–0.4, период 3–5 с; луна — `Sky` (scene-state).
- Дождь «грустно»: 60–90 штрихов, угол 5–10°; «буря»: 180–220, угол 15–20°, + `Fog`.
- Снег: дальний слой отдельным `<Snow>` под холмами (`count` 60, `speed` 0.08, `opacity` 0.7),
  ближний — поверх всего; так снег получает глубину.
- Утро/тишина: `GodRays` + `Dust`, фон темнее луча (на светлом фоне пыль не видна).
- Акцент: `Burst` в кадр ключевого слова (по `words.json`), 18–24 кадра, не чаще раза в 2–3 с.

## Чеклист

- [ ] Частицы не закрывают героя и текст: плотность ниже у текста, или `area`/`clipPath`.
- [ ] Нет «телепортов»: на ленте кадров (`studio sheet --frames a-b`) частицы входят из-за края.
- [ ] Темп частиц совпадает с темпом речи (спокойная речь — медленные частицы); на развязке — пик.
- [ ] Эффект читается на плитке размера телефона (контраст к фону, толщина, плотность).
- [ ] Мерцание звёзд медленное (период ≥ 2 с), не синхронное.
- [ ] Молния: ≤ 1–2 вспышки на сцену, сила ≤ 0.5 — иначе probe увидит склейку, а зритель — мигание.
- [ ] 3D-объём частиц больше видимой области (перенос не виден); облака — за героем.
- [ ] `studio probe` черновика: нет `fast-motion` от частиц (крупные близкие частицы быстрее всего).

### Известное про probe

Нижняя плоская полоса (последняя волна, земля одним цветом) даёт `cover-gap` — ложное
срабатывание на векторной заливке; `Grain` его не снимает (probe смотрит уменьшенный кадр).
Проверьте глазами.
