# Каталог скиллов студии

Одна строка на скилл: когда брать. Директор читает этот список, затем карточки нужных скиллов (`studio skill <имя> …` — ≈ 30 строк: когда, API, ловушки); раздел подробностей — `studio skill <имя> --section <раздел>`, когда упёрся. Скиллы — знания и стартовые точки, не рецепты. Точные подписи компонентов — `studio api <модуль>`.

## Направление (`direction`)

- `art-direction` — Стиль-библия ролика (theme.json): палитра, шрифты с кириллицей, материал, хвост промптов картинок, темперамент, вид подписей; проверка и лист стиля PNG (board.ts). Брать первым шагом после брифа, до любых ассетов.
- `beat-planner` — Раскадровка от звука (beats.json): черновик нарезки по словам и фразам (beats.ts suggest), проверка, `<Beats>` в сцене; склейки только на границах слов. Брать после озвучки.
- `transitions` — Переходы между битами: склейка на слове (смена плана — не «прыгает»), fade, slide, wipe, смена фона; растворение без «призрака» героя; мотивированный выход/вход через край. Брать при сборке сцен.
- `sound-design` — Звук: голос, своя музыка под ролик (`studio music --make/--plan`) или из каталога (`studio music`), атмосфера места (bed.ts: дождь, море, ветер, город), звуки событий в паузах речи, −14 LUFS; проверка глазами (mixcheck: волна, речь, попадание, дыры). Брать всегда.

## Правда (`truth`)

- `claims-and-compliance` — Что ролик утверждает словом и картинкой: факты брифа (`studio facts` — даты/дни недели, числа, категория), реестр утверждений, якоря реальности (товар, зал, люди — фото заказчика или честная заглушка), регулируемые категории РФ и обязательные пометки, «## Вопросы заказчику». Брать на шаге «бриф → цель» для любого промо.

## 2D-ремесло (`craft-2d`)

- `kinetic-typography` — Живой текст на кириллице: субтитры по словам (Captions: страницы, плашки ключевых фраз), заголовок-крючок (Headline), счётчик без дрожи (Counter), смена текста в плашке (SwapText); иерархия «главное — крупнее». Брать, когда есть речь или текст на экране.
- `paper-2d` — Бумага, коллаж, аппликация (`@studio/paper-2d` + бумажный набор `@studio/paper-kit`): рваные листы, волны со строчкой, подвесы на нитках, лодка на волнах, луч, бумажные куклы и декорации; игра героя (fall/hop/squash). Брать для тёплого ручного стиля, сказки и дешёвого рендера.
- `explainer-cards` — Карточки-объяснялки и макеты интерфейсов (`@studio/explainer-cards`): шаг с огромной цифрой, терминал, чек-лист, схема плиток, цикл, стикер, документ. Брать для обучения, процессов, сравнений.
- `data-viz` — Цифры и графики (`@studio/data-viz`): счётчик без «дрожи», столбики от нуля, линия с меткой, кольцо, бублик, пиктограмма «k из n». Брать, когда в речи есть числа или сравнения.
- `generated-imagery` — Сгенерированные картинки (studio image, `@studio/generated-imagery`): 9 стилей (7 мультяшных), фоны, вырезки без ореола, лист персонажа и тот же герой по `--ref`. Брать, когда нужного изображения нет.
- `fx-particles` — Частицы: дождь, снег, звёзды, пыль, облака — строго от кадра и сида. Брать для погоды, ночи, сказочности, акцента.
- `presentation-frame` — Упаковка для соцсетей: окно, рамка, «экран ноутбука», постоянный заголовок. Брать по формату площадки, необязательно.

## 3D (`three-d`)

- `blender-asset-factory` — Процедурные 3D-ассеты в Blender без окна (studio blender + poly/looks/scene3d): диорамы и пропсы из примитивов (остров, домики, маяк, мельница, деревья, вода), GLB с паспортом, кадры и PNG-секвенции. Брать, когда нужен 3D-объект или мир.
- `object-scene-3d` — Товар или объект в 3D/2.5D: студийный свет, тень, камера (@remotion/three или параллакс фото). Брать для продуктовых и герой-кадров.
- `typography-3d` — Объёмные надписи с кириллицей: Blender text → mesh (TTF Google Fonts, фаска, проверка глифов), буквы отдельными узлами для анимации в three. Брать для заголовка-удара, цифры-героя, логотипа.
- `scene-state` — Свет, погода, время суток, сезон как параметры сцены с плавным смешиванием пресетов. Брать, когда у сцены есть настроение или его смена.
- `materials` — Материалы-виды с одинаковым видом в Blender и three (clay, lowpoly, felt, paper, toon, plastic, ceramic, metal, glass, emissive, label), тон-маппинг, перекраска групп и свечение. Брать вместе с 3D-скиллами.

## Качество (`quality`)

- `camera-choreography` — Движение камеры и слоёв без рывков: камерные биты под события истории, Ken Burns с гарантией покрытия, лимиты скорости для камеры и законы мультипликации для игры. Брать для любого движения кадра.
- `layout-guard` — Защита кадра: зоны площадки, фон покрывает кадр, текст влезает (FitText); FrameAudit ловит вылет за край на любом фоне, текст под интерфейсом, мелкий текст и пустые плашки; роли data-hero/data-acting/data-bleed. Брать всегда.
- `self-review` — Самопроверка одной командой (review.ts): lint + check + черновик с треками + probe + цифры ленты (крючок, размер героя, застой, без звука, контраст по пикселям) + плитки размера телефона → вердикт, вопросы ленты; критик со свежим взглядом (critic.md). Брать перед каждым финальным рендером.
