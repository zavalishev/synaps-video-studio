# explainer-cards — объяснение, которое собирается на глазах

## Карточка

**Зачем**: карточки-объяснялки и макеты интерфейсов — шаг с огромной цифрой, терминал, чек-лист,
схема плиток, цикл, стикер, документ. Для обучения, процессов, сравнений.

**API** (`@studio/explainer-cards`): `Card`, `WindowChrome`, `Terminal` (+`termSchedule`),
`Checklist`, `StepCard`, `FlowGraph`, `LoopDiagram`, `StatPill`, `StickyNote`, `DocCard`,
`cardIn`, `cardTheme(theme, {font, mono, serif?, hand?})`, `drawOn(g, d, stroke)` (линия рисуется без точки на старте). Тема `CardTheme` — только из theme.json (`cardTheme`: palette + shapes); готовых палитр нет;
форма (`radius`/`shadow`/`border`) — из `theme.shapes`, не умолчание компонента.

**Правила**:
- Карточка несёт одну мысль бита; цифра — герой, а не подпись в карточке (крупно, на
  поверхности мира, наезд между цифрами).
- Схема на телефоне — ≤ 5 значимых элементов крупно; сетка календаря/таблица — фон-контекст,
  к которому камера приближается (2–3 нужных дня во весь кадр), а не план на 4 с.
- Порядок подписей на итоговой схеме = порядок истории; подпись не лежит на герое.
- «Камера стоит, двигаются карточки» — цена: застой (`stale`); что обновляет внимание?
- Живой бизнес (касса, накладная, витрина) рядом со схемой — ролик «про нас», а не банк-приложение.

**Схема реального предмета** узнаваема для профессионала: силуэт по референсу (резцы и клыки,
дуга, а не восемь одинаковых таблеток); не выходит достоверно — кадр того же мира
(`studio image --ref`), а схема — для того, что фото не покажет.

**Ловушки**: пустая карточка с заголовком дольше 1 с — «ждущий кадр»; композиция «от верха
как веб-страница» — низ пустой (`top-heavy`): `composeV` из camera-choreography.

## Подробности (читать по нужде: `studio skill explainer-cards --section <раздел>`)

Жанр «чистая анимированная инфографика» (ref5: тёплый минимализм, терракотовый акцент,
курсивные ключевые слова, моно-подписи). Карточка несёт **одну мысль бита**; текст в ней —
короткий, пишет его директор под тему ролика.

«Камера стоит, двигаются карточки» — один из вариантов, и у него есть цена: в ленте 40 секунд
одного листа с появляющимися строками — лекционный слайд (probe: `stale`). Решите в концепте,
что обновляет внимание каждые несколько секунд: наезд к ключевой строке/цифре на развязке,
смена масштаба (схема → деталь), новый предмет, перенос героя-визуала в новое состояние.
Инфографика без контекста — «банковское приложение»: живой бизнес (касса, накладная,
витрина, владелец — paper-2d / generated-imagery) рядом со схемой делает ролик «про нас».

## Когда брать

- Обучение, инструкция, «3 шага», процесс, схема «кто с кем связан», цикл «каждый день».
- Демонстрация продукта без съёмки экрана: терминал, окно, чек-лист, документ.
- Не брать: сказка, эмоция, персонаж в центре — там paper-2d / generated-imagery / 3D.

## Что есть

| Компонент | Для чего | Ключевое |
|---|---|---|
| `Card` | поверхность с радиусом и тенью, наклон в перспективе | `tilt` ≤ ±10° (больше — `card-tilt` в guard.json) |
| `WindowChrome` | окно с полосой и тремя точками (без чужих логотипов) | `dark`, `title` |
| `Terminal` | команды печатаются, вывод появляется, курсор мигает от кадра | `lines[{text, kind: cmd/out/ok/err/note, at?}]`, `cps` |
| `Checklist` | пункты входят, галочки рисуются, текст зачёркивается, «ГОТОВО k/n» | `items[{text, at}]`, `counter` |
| `StepCard` | «шаг» + огромная градиентная цифра + сегменты прогресса | вход размытие→резкость, без «вжуха» |
| `FlowGraph` | плитки и кривые Безье, рисуются по длине; бегущая точка «данные идут» | `nodes[{id,x,y,title,sub,tone,at,status}]`, `edges[{from,to,at,pulse}]` |
| `LoopDiagram` | пунктирный круг, фишки по кругу, бегунок (период 4 с) | `items`, `center`, `active` |
| `StatPill` | плашка «подпись + число со счётом» | на `Counter` из data-viz |
| `StickyNote` | стикер с загнутым углом, текст «пишется» | рукописный шрифт `theme.hand` |
| `DocCard` | документ из настоящих строк, маркер проводится по строке | наезд камеры — `CameraView` из @studio |
| `cardIn(f, at)` | мягкий вход любой своей карточки (подъём, масштаб, прозрачность) | без перелёта |
| `termSchedule()` | расписание печати: когда строка начинается/заканчивается | чтобы склейку/звук поставить на конец команды |

## Как

```tsx
import * as Display from "@remotion/google-fonts/<fonts.display.module>"; // из theme.json
import * as Mono from "@remotion/google-fonts/JetBrainsMono";
import * as Accent from "@remotion/google-fonts/<fonts.accent.module>";
import * as Caveat from "@remotion/google-fonts/Caveat";
import { Guarded, useCyrillicFont } from "@studio";
import { zones } from "@studio/layout-guard";
import { Checklist, FlowGraph, StepCard, Terminal, WindowChrome, cardIn, cardTheme } from "@studio/explainer-cards";
import theme from "../theme.json";

const t = cardTheme(theme, {                              // цвета и форма — из арт-дирекции ролика
  font: useCyrillicFont(Display, { weights: ["500", "700", "800"] }),
  mono: useCyrillicFont(Mono, { weights: ["400", "700"] }),
  serif: useCyrillicFont(Accent, { style: "italic", weights: ["500"] }),
  hand: useCyrillicFont(Caveat, { weights: ["600"] }),
});
const S = zones(W, H, undefined, { theme }).heroMax;     // размеры — доли зоны героя, не пиксели

<Guarded id="step" box={{ x: S.x, y: S.y, w: S.w, h: Math.min(S.h, S.w) }}>
  <StepCard n={2} total={5} theme={t} label="шаг" caption="ШАГ 02 / 05" start={2} />
</Guarded>

<Guarded id="term" box={{ x: S.x, y: S.y, w: S.w, h: S.w * 0.62 }}>
  <div style={cardIn(frame, 4)}>
    <WindowChrome w={S.w} h={S.w * 0.62} theme={t} dark title="~/кофейня — агент" tilt={{ x: 4, y: -6 }}>
      <Terminal theme={t} px={S.w * 0.045} start={14} cps={30} lines={[
        { text: "подключи таблицу продаж" },
        { text: "нашёл лист «Октябрь», 1 248 строк", kind: "out" },
        { text: "подключено", kind: "ok" },
      ]} />
    </WindowChrome>
  </div>
</Guarded>

<FlowGraph width={S.w} height={S.h} theme={t} nodeW={S.w * 0.44} nodeH={S.w * 0.18} px={S.w * 0.05}
  nodes={[{ id: "a", x: S.w / 2, y: S.h * 0.14, title: "Агент", sub: "мозг", tone: "accent", at: 2 },
          { id: "b", x: S.w * 0.24, y: S.h * 0.76, title: "Таблица", sub: "продажи", at: 12, status: { text: "подключено", at: 40 } }]}
  edges={[{ from: "a", to: "b", at: 20, dur: 20, pulse: true }]} />
```

Ключевое слово-перебивка (курсивная антиква, двухцветное: нейтральное + акцент) — обычный
div с `cardIn(f, at, { blur: 10 })`
(`Keyword`). Шрифт без кириллицы (Instrument Serif, Fraunces) брать нельзя — замены ищите голосом
`studio fonts --suggest display-serif`.

Ритм: карточка входит на слове, которое её называет; печать терминала — 25–35 символов/с
(быстрее — не читается); галочка — на слове «готово/сделано»; держать готовую карточку ≥ 1 с.
Склейку и звук «клика» ставьте на `termSchedule(...)[i].end` или на `items[i].at`.

## Цвета и форма — из ролика

Готовых палитр нет: `cardTheme(theme, шрифты)` берёт bg/ink/accent из `theme.palette`
(поверхности, линии, мягкий акцент — смесью в OKLCH; своё значение роли — ключом в palette)
и радиус/тень/рамку из `theme.shapes`. Прошлые «тёплый минимализм с терракотой» и «ночь с
мятой» стали домом студии — поэтому их больше нет.

## Схема на вертикальном кадре

- Подпись — рядом со своим предметом (или с выноской), а не там, где осталось место.
- Вывод/ключевые слова — самый крупный текст кадра (не мельче обычных подписей).
- Схема 9:16 занимает высоту: сначала впишите её в высоту безопасной зоны, потом в ширину;
  пустая нижняя треть под схемой — знак, что масштаб мал (review: `dead-band`, `sparse`).
- Вывод показывается тем же визуальным языком, что и проблема (тот же график/схема в новом
  состоянии), а не сменой жанра на таблицу.

## Подводные камни

- Карточка шире безопасной зоны или вылетает при входе — оборачивайте в `Guarded`
  (вход `cardIn` двигает на ≤ 28 px вверх, это внутри коробки).
- Моно-текст переносится только по пробелам; длинный путь/команда без пробелов вылезет —
  сократите строку или уменьшите `px`. Кегль терминала на 1080 по ширине — ≥ 34 px.
- Наклон > 10° и одновременный наклон всех карточек — «пьяный» кадр; наклоняйте одну героиню.
- Бегущая точка `pulse` и бегунок цикла — постоянное движение; на коротком бите (< 2 с)
  выключайте, чтобы не спорить с текстом.
- Чужие логотипы и бренды (в том числе Anthropic/Claude) не рисуем; только свой знак или
  нейтральная плитка.
- Не больше двух типов переходов на ролик (скилл transitions); между карточками — уход
  до входа, без двойной экспозиции текста.

## Чеклист

- [ ] Одна мысль на карточку, ≤ 7 слов в заголовке; текст пишет директор, не «лорем».
- [ ] Всё внутри безопасной зоны в каждом кадре входа и выхода (still --probe: рамки зелёные).
- [ ] Кегль всего, что надо прочесть, ≥ 3.5 % высоты; мельче — только декор (`data-decor`);
      вывод — крупнее остальных подписей.
- [ ] Под речью кадр обновляется каждые несколько секунд (не только новые строки текста).
- [ ] Контраст текста к поверхности ≥ 4.5 (`contrast()` из @studio).
- [ ] Печать читается (≤ 35 симв./с), курсор мигает от кадра, а не CSS-анимацией.
- [ ] Вход без перелёта, движение ≤ 0.6 %W/кадр (probe), наклон ≤ 10°.

## Проверено

Проверочный ролик — шаг, терминал в окне с наклоном + плашка-счётчик, схема
из трёх плиток со связями, цикл, чек-лист со стикером. probe: PASS (макс. 0.18 %W/кадр),
guard без нарушений. Лист кадров: `out/sheet-final.png`; крупно — `out/stills/f0140.png` (терминал), `f0215.png` (схема), `f0360.png` (чек-лист).
