# transitions — переход как пунктуация

## Карточка

**Зачем**: монтаж как пунктуация — склейка на слове по умолчанию, мягкие переходы по мотиву,
проверка монтажа до рендера. Против блюр-«вжухов» и мельтешения.

**API** (`@studio/transitions`): `dissolve`, `push`, `dipTo`, `softWipe`, `softIris`, `settle`,
`softTiming`; монтаж данными `<Edit shots/>` + `layoutEdit(shots)` (→ cuts для probe) +
`checkEdit(shots, {fps})`; `useShot()`, `useShotTextOpacity()` — текст гаснет до перехода.

**Правила**:
- Склейка на слове — не «прыгает»; новый план на фразе — главный инструмент удержания.
- Не больше двух видов переходов на ролик (склейка не считается); блюр ≤ 6 px.
- Растворение смешивает кадры: твёрдого героя убрать до перехода или менять место склейкой
  по действию — иначе «призрак».
- Мотивированный выход через край: `data-bleed`, следующий план продолжает движение в ту же
  сторону, тот же масштаб.
- Склейка = смена крупности (≥ ×1.5) или угла (правило 30 %); тот же план со сдвигом героя —
  скачок (review `jump-cut`). Не меняется — не режь: одно непрерывное движение камеры.
- Мягкий звук на склейке (страница, вдох, подъём к кульминации) — можно: запрет вжухов про картинку.

**Ловушки**: переход < 8 кадров читается как рывок; dissolve < 16 и dip < 40 кадров probe
видит как склейку — внеси в план; двойная экспозиция подписей на переходе.

## Подробности (читать по нужде: `studio skill transitions --section <раздел>`)

Владелец отклонил «быстрый» ролик: блюр-вжухи, жёсткие склейки подряд, пролёты через весь
кадр. Темп ролика делает **монтаж на слове**, а не размазанный кадр. Переход должен быть
мотивирован: смена места/времени, вход в деталь, конец раздела. Если мотива нет — чистая
склейка на границе слова почти всегда лучше любого эффекта.

## Как выбирать

| Мотив | Переход | Длина (30 fps) |
|---|---|---|
| новая мысль, тот же мир; сказка между планами | **склейка на слове** (`cut`) | 0 |
| время прошло, место сменилось мягко | `dissolve` (можно `settle: 0.02`) | 24–30 |
| следующий пункт/шаг, «листаем» | `push` — сдвиг на 2–7 % кадра + проявление | 24–30 |
| конец раздела, светлое ↔ тёмное | `dip` через цвет | 44–50 |
| свет/время проходит по кадру | `softWipe` (мягкая граница, угол) | 24–30 |
| из объекта в его мир (лампа → комната) | `softIris` из точки объекта | 26–30 |
| «входим глубже» в тему | `settle` (наезд-растворение ≤ 8 %) | 20–26 |

На ролик — **не больше двух видов** переходов (склейка не считается). Один и тот же вид
повторяется — это ритм; новый вид каждый раз — это мельтешение.

**Склейка на слове — не «прыгает».** Владелец отклонил вжухи, пружины и склейки подряд
(> 2 в секунду), а не смену плана. Новый план (общий → деталь → рука → дверь) на слове —
главный инструмент удержания в ленте; «ноль склеек за 20 секунд» — не достоинство, если
кадр всё это время один.

### Растворение и твёрдый герой

Растворение смешивает два кадра: полупрозрачный предмет поверх нового фона читается как
«призрак», двойная экспозиция — особенно стекло и вырезки. Перед растворением места
**уберите героя** (он уходит/опускается/закрывается раньше перехода) или меняйте место
**склейкой на слове** / **по действию** (match-action: рука ставит чашку — склейка — та же
чашка на другом столе). Вход твёрдого предмета — движением, шторкой или масштабом с тенью
(`Cutout enter.kind: "land" | "mask"`), а не проявлением из прозрачности.

### Мотивированный выход и вход через край (match on action)

Персонаж улетает вверх из кадра — склейка — влетает снизу на следующем плане: зритель видит
путь («поднялась»), а не телепорт. Это не «уезжает за край»: выход нарочный и продолжается.
- слой помечается `data-bleed` (FrameAudit не ставит edge-cut; probe `edge-crossing` в
  review понижается до INFO, но ленту смотрите глазами);
- выход быстрый (игра, `data-acting`: ускорение `fall`/`anticipate`), склейка — в момент,
  когда предмет почти вышел; на следующем плане он входит с той же стороны, куда ушёл
  (вверх → снизу), в том же масштабе и с той же скоростью;
- камера при этом стоит или едет медленно — лимиты кадра остаются для камеры.

## Что есть (`@studio/transitions`, `studio/lib/transitions/index.tsx`)

- Презентации для `TransitionSeries` из `@remotion/transitions`: `dissolve`, `push`, `dipTo`,
  `softWipe`, `softIris`, `settle`; `softTiming(dur, ease)`; плавности `TEASE`, `SOFT`.
  Блюр ограничен 6 px, push не пролетает кадр, у `dip` плавность внутри каждой половины.
- **Монтаж как данные**: `<Edit shots={[{id, dur, el, into: {kind, dur, …}, hook?}]} />`.
- `layoutEdit(shots)` → `{total, shots[{id, from, to}], cuts[], transitions[]}` — где что
  окажется на таймлайне (переходы перекрывают кадры, общая длина меньше суммы!). `cuts` —
  прямо в `studio probe --cuts`.
- `checkEdit(shots, {fps})` — до рендера: ≤ 2 смены в секунду, кадр ≥ 0.6 с (кроме `hook`),
  переход ≤ 30 % соседнего кадра (`dip` — половина), ≤ 2 вида переходов, блюр ≤ 6 px,
  push не быстрее лимита (`pushMaxDistance(dur)`), переход < 8 кадров = рывок, растворение
  < 16 кадров и dip < 40 кадров между разными кадрами probe читает как склейку.
- `useShot()` / `useShotTextOpacity()` — кадр знает длину своих переходов: текст проявляется
  после входного перехода и гаснет до выходного — **без двойной экспозиции подписей**.

## Как

```tsx
import { Edit, type Shot, checkEdit, layoutEdit, useShot, useShotTextOpacity } from "@studio/transitions";

const SHOTS: Shot[] = [
  { id: "cafe", dur: 96, el: <Cafe /> },
  { id: "cup", dur: 96, el: <Cup />, into: { kind: "dissolve", dur: 26, settle: 0.02 } },
  { id: "steps", dur: 124, el: <Steps />, into: { kind: "dissolve", dur: 24 } },
  { id: "count", dur: 120, el: <Counter />, into: { kind: "dip", color: "#17151f", dur: 48, hold: 0.06 } },
  { id: "evening", dur: 84, el: <Evening />, into: { kind: "cut" } },          // склейка на слове «вечером»
];
export const Video = () => <Edit shots={SHOTS} />;

// В кадре: подпись не накладывается на подпись соседнего кадра
const op = useShotTextOpacity();                     // 0 → 1 после входа, 1 → 0 перед выходом
// Анимация «после перехода», а не в темноте dip:
const t0 = useShot()?.inDur ?? 0;                    // счёт начинается с t0 + 4
```

До рендера (node, секунды) — `assets/plan-check.ts`:

```ts
import { checkEdit, layoutEdit } from "../../../studio/lib/transitions";
console.log(layoutEdit(PLAN).cuts, checkEdit(PLAN, { fps: 30 }));   // PLAN — те же {id, dur, into} без el
```

Длина композиции = `layoutEdit(...).total` → `job.json.durationInFrames` (или аудио).
Склейки ставьте на границы слов из `words.json` (`beat-planner`): `from` кадра = кадр начала
слова. Звук события (`sound-design`) — на `cuts` и на середину переходов.

Без `Edit`: `<TransitionSeries>` напрямую с `presentation={dissolve()} timing={softTiming(24, SOFT)}`;
смена фона светлый ↔ тёмный внутри одного кадра — `interpolateColors` за 20–30 кадров.

## Стартовые точки (необязательно)

- Сказка (ref1): склейки на слове, кадр 3–5 с, один `dissolve` на смену времени суток.
- Объяснялка (ref5): склейки на ключевых словах 1.5–3 с + `dip` между разделами (≤ 2 вида).
- Тёплый промо (ref4): `dissolve`/`push` на ключевых словах 1.5–3 с, без жёстких склеек.
- Хук первые 3–5 с: кадры можно короче (`hook: true`), но всё равно ≤ 2 смен в секунду.

## Чеклист

- [ ] `checkEdit` — пусто; `layoutEdit.total` = длина ролика.
- [ ] ≤ 2 вида переходов; каждый переход имеет мотив (записан в notes.md одной фразой).
- [ ] Нет блюр-вжухов, нет пролёта кадра целиком, нет пружин с перелётом.
- [ ] Растворение не оставляет полупрозрачного героя поверх нового места (лента перехода).
- [ ] Нарочный выход через край (`data-bleed`) продолжается на следующем плане в ту же сторону.
- [ ] Подписи не накладываются во время перехода (`useShotTextOpacity` или текст уходит раньше).
- [ ] Во время перехода кадр не пустой: входящий контент на месте к середине перехода.
- [ ] Анимации кадра стартуют после входного перехода (`useShot().inDur`), не в темноте dip.
- [ ] `studio probe draft.mp4 --cuts <layoutEdit.cuts>` — нет `unplanned-cut`, `cut-rate`, `blur-transition`.
- [ ] Лента кадров через каждый переход (`studio sheet --frames a,b,c…`) — глазами.

### Известное про probe

- Растворение в кадр с ровной однотонной заливкой сверху (бумажный фон) может дать
  `cover-gap` на кадрах перехода — ложное срабатывание (кадр перестаёт быть «плоским»
  только на время смеси). Смотрите ленту.
- Резкая смена яркости быстрее ~0.07 яркости за кадр — склейка для probe. Поэтому `dip`
  светлое → тёмное ≥ 44 кадров, растворение между разными кадрами ≥ 24 и `SOFT`.
