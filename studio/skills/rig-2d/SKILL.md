# rig-2d — герой из частей на шарнирах

## Карточка

**Зачем**: картинка даёт рисунок, но неподвижна; кукла кодом двигается, но рисунок беден.
Здесь генератор рисует героя ПО ЧАСТЯМ, код собирает их на шарнирах и двигает готовыми
движениями — как скелетная анимация в играх (Spine/Rive). Режиссёр решает, что герой делает
и когда; суставы, инерцию, дыхание и моргание считает движок.

**Путь (4 шага, ~3 мин)**:
0. Сначала реши по сценарию: **герой будет идти через кадр** (дольше пары шагов)? Да — лист сразу
   в профиль (`--side`, ноги бедро+голень, промпт ниже). Анфас-лист для героя, который в основном
   говорит, машет, радуется и подходит на полроста. Один лист на ролик — выбирай до генерации.
1. Лист частей — одна картинка `studio image … --size 1536x1024 --bg transparent --quality high`
   (промпт ниже; `--ref` на лист персонажа, если он уже есть). Открой картинку Read-ом.
2. `studio rig cut public/rig/<имя>-parts.png --name <имя>` (герой в профиль с коленями — с `--side`;
   предмет-персонаж — с `--object --limb "#цвет"`): части в public/rig/<имя>/, скелет-черновик
   rig.json, лист с подписями.
3. `studio rig check public/rig/<имя>/rig.json --joints` → лист поз (rest, walk, wave, hop,
   cheer, talk, surprise, sleep). Плечо оторвано, голова висит, нога торчит — поправь `at`
   (точка на родителе) / `pivot` (сустав на части) / `z` в rig.json и снова check. 1–2 круга.
   Герой ходит — ещё `studio rig check public/rig/<имя>/rig.json --strip walk` (и `--strip run`):
   лента шага через кадр с метками пола и число «опорная стопа стоит в N % кадров». Красная точка
   стопы должна стоять на своей метке; ВНИМАНИЕ в выводе — поправь колено (`at` голени на бедре)
   и `pivot` ног.
4. В сцене:
```tsx
import rig from "../../public/rig/bear/rig.json";
import { Rig, talkFromWords, type RigDef } from "@studio/rig";
import words from "../../public/words.json";
<Rig rig={rig as RigDef} x={540} y={1650} height={820} actions={[
  { do: "walk", at: 0.2, to: [620, 1650] },          // ходьба к точке (скорость сама; dur — свой темп)
  { do: "surprise", at: 1.9 }, { do: "wave", at: 2.4, arm: "R" },
  { do: "hop", at: 4 }, { do: "cheer", at: 5, dur: 1.2 },
  ...talkFromWords(words, { ids: ["hello"], offset: 0 /* начало сцены, с */ }),
]} />
```
x, y — точка на земле под героем (ставь на пол фона), height — рост в px (герой ≥ 35–45 %
высоты кадра). Время действий — секунды от начала сцены.

**Действия**: `walk`/`run`/`move` {to, dur?, face?} · `hop` {h?} · `wave`/`point` {arm: "L"|"R",
angle?} · `cheer` · `talk` {dur} · `surprise` · `sleep` {dur} · `look` {angle} · `nod` ·
`shiver` · `turn` {facing: 1|-1} · `reach` {arm: "L"|"R", to: [x, y], dur} — тянуться рукой к точке
кадра (взять за руку, протянуть, держать предмет; длина руки не меняется) · `pose` {angles: {armL: 90, head: -10, …}, lean?, dy?, alt?,
dur, ease?} — своя ключевая поза (руки/ноги — градусы «наружу»: 0 вниз, 90 в сторону, 180
вверх). Действия накладываются (идёт и говорит, машет и подпрыгивает).

**Промпт листа (человек/зверь)**: «Cutout animation puppet parts sheet of ONE character: <кто,
одежда, приметы>, <стиль из theme.json>. Draw the character DISASSEMBLED into separate body parts
on a transparent background with wide empty gaps (no part touches another): top row — the head
facing the viewer (no neck), the same head with eyes closed, the same head with mouth wide open;
middle — the torso with clothes (no arms, legs, head), left of it the left arm hanging straight
down (shoulder at top), right of it the right arm hanging straight down; bottom row — left leg and
right leg standing straight (hip at top, foot at bottom). Each part whole, rounded at the joint
end. No text, no labels, no shadows, no background.»
**Предмет-персонаж** (`--object`): «… the SAME <предмет> character three times in a single row with
wide gaps: eyes open smiling; eyes closed; mouth wide open. Body only — NO arms, NO legs …» —
ручки-ножки рисует код (hose: цвет `--limb`, толщина, длина — в rig.json).

**Ходьба** считается от пройденного пути, а не от часов: опорная стопа стоит на полу, маховая
переносится вперёд с подъёмом. Характер шага — мультяшный: короткий частый шаг (~1,6–1,8 шага в секунду,
шаг ~0,7 длины ноги; медленнее — шаг короче и реже, как у живых), руки догоняют ноги с запаздыванием в 2–3 кадра, голова кивает на каждом
шаге, корпус наклонён вперёд и покачивается вверх-вниз по шагу, а после остановки корпус по
инерции качается вперёд, откатывается назад и встаёт (~0,65 с). Всё это движок делает сам. Поэтому:
- Герой, который ходит через кадр, — **в профиль** (`"view": "side"`), лучше с коленями:
  на листе ноги нарисованы двумя частями (бедро и голень с ботинком: legL/shinL, legR/shinR) —
  тогда шаг настоящий, колено сгибается само. Промпт листа: «… legs drawn as two parts each:
  thigh (hip at top) and shin with foot (knee at top), facing right».
- Нарисованный **анфас** (`"view": "front"`) при движении вбок семенит: ноги поочерёдно
  переступают под телом, каждая стопа уходит от своего места лишь на мелкий шажок (не больше 0,7
  расстояния между ногами — ноги не расходятся циркулем и не перекрещиваются), колено не гнётся —
  нога прямая. Как у мультяшных героев анфас (чашка с ножками, Clawd). Годится на
  подход до роста, не для прогулки через кадр. Дальше — в профиль, или анфас идёт «к зрителю»
  (смена плана), или `move` с прыжками. Самопроверка предупредит (`rig-front-walk`), если анфас
  идёт вбок дальше своего роста.
- **Скорость можно не задавать**: без `dur` она считается от длины ноги (ходьба ≈ 1,1 длины ноги
  в секунду, бег ≈ 2,7 в профиль и 2,4 анфас), но не медленнее 0,4 роста/с (бег — 0,9): длинноногий
  идёт быстрее коротконогого. Свой `dur` можно: шаг сам станет короче и реже (медленно) или длиннее
  и чаще (быстро) в пределах 0,6–0,9 длины ноги (анфас 0,25–0,5). Быстрее предела шаг упирается в
  потолок и только учащается — герой семенит, лучше `run`; медленнее — шаг остаётся 0,6 ноги и
  становится реже — замедленная прогулка.
- Переходы идут очередью: `walk`, начатый раньше, чем кончился предыдущий, ждёт его конца (герой
  не перескакивает). Когда важно, где герой будет в момент реплики, — задай `dur`.
- Длина шага сама подгоняется под путь: герой трогается и останавливается со стопами вместе.
  Короткий путь (меньше ~0,2 роста) — это один шаг; если нужен «топчется на месте» — `pose`, не `walk`.
- В профиль `wave`/`point` без `arm` поднимает **ближнюю** к зрителю руку (ту, что рисуется сверху);
  дальнюю указывай явно, только если она по смыслу нужна.
- Два героя в кадре дышат и моргают каждый в своём ритме — по `id` у `<Rig>` (нет `id` — по имени
  скелета). Два одинаковых героя — давай им разные `id`.

**Правила**:
- Руки и ноги — **только через `<Rig>`**. Не вырезай части из rig.json и не рисуй их своими `<Img>`/матрицами:
  картинка руки, растянутая до цели, сплющивается и «отрывается», плечо улетает выше головы (самопроверка:
  `rig-parts-bypass`). Взять за руку, протянуть, указать на предмет — `reach` {arm, to: [x, y]}; предмет в руке —
  `handAt(rig, actions, t, {x, y, height}, "R").hand` (плечо и длина руки там же). Двое за руки — оба `reach`
  к одной точке между ними, на ~полруки ниже плеч (у героя поменьше — по его плечу); точка дальше длины руки —
  подвинь героев ближе, а не тяни руку.
- Поднятая рука (`wave`, `cheer`, `pose` 120°+) у края кадра уходит за кадр — поднимай руку, что ближе к
  центру, или отодвинь героя от края.
- Каждый лист частей — `rig check --joints` до сцен: рука на листе согнута, нарисована «трубкой» или плечо не
  сверху — переделай лист (рука висит прямо вниз, плечо сверху), иначе сустав встанет не туда.
- Фон — та же рука: тот же `imagePromptSuffix` и стиль, что у листа; свет фона ≈ свет героя
  (`filter` у Rig подстроит тон), тень под ногами есть сама.
- Герой всегда жив: между событиями — дыхание и моргание сами; не держи его «на паузе» дольше
  2 с без действия — `look`, `nod`, переступить (`move` на 20–40 px).
- Событие истории = действие героя в кадре (испугался — `surprise`, обрадовался — `cheer`,
  уснул — `sleep`), а не надпись.
- Говорит — `talkFromWords(words, { ids: [...], offset })` по его репликам: рот открывается на слогах
  слов озвучки и закрыт в паузах. Не держи рот открытым через `pose` `{ alt: { head: "talk" } }` на
  всю сцену — зритель видит застывшую улыбку, а не речь; `pose` с `talk` — только для крика/«ах!».
- Один лист на героя на весь ролик: тот же rig.json во всех сценах — герой одинаковый.

**Ловушки**: части на листе касаются друг друга — cut склеит их (переделай лист: «wide gaps»);
лишние части (тень, надпись) — в rig.json попадут в `unused`, их можно удалить; ореол по краю
снимается при резке; рука при `wave` уходит за голову — z руки 1 вместо -1 (тогда плечо видно,
поправь `at`). Герой в профиль — `"view": "side"` в rig.json (шаг вразмах). Ноги при шаге
поднимаются целиком (`off`), картинка ноги не сплющивается.

## Подробности

Скелет `rig.json`: `parts` — часть → { src, w, h, parent, at: [x, y] на родителе, pivot: [x, y]
своего сустава, z, rest (исходный угол), alt: { blink, talk } (сменные картинки того же размера),
follow 0..1 (уши, хвост, волосы — отстают и покачиваются), hose: { len, width, color, outline?,
endR?, endColor? } (резиновая конечность кодом) }. Корень — часть без parent (туловище), его
pivot — бёдра. Дети резиновой конечности крепятся к её концу.

Имена, которые знают движения: torso, head, armL, armR, legL, legR (L — слева на экране),
вторые звенья forearmL/R, shinL/R — по желанию (лист с локтями и коленями отдельно). Нет head —
моргание и рот берутся из alt туловища (предмет-персонаж).

Математика — чистая функция кадра (`@studio/rig` → evaluate, drawList): рендер параллелится,
`studio rig check` рисует те же позы без Remotion.
