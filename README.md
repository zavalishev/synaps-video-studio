# AI Video Studio

**Агентная студия моушн-дизайна для коротких вертикальных роликов: Reels, Shorts, TikTok.**
Вы пишете бриф, Claude Code по вашей подписке работает режиссёром, на выходе готовый MP4.

> Сделано: <ваше имя, команда или ссылка>

[English version](README.en.md)

Режиссёр не заполняет шаблон. Он читает бриф и руководство студии (`studio/CLAUDE.md`), сам
придумывает концепт, выбирает стиль, шрифт, палитру, камеру и темп, собирает сцены на
[Remotion](https://www.remotion.dev), смотрит кадры, проверяет себя и выпускает ролик. Двадцать
скиллов студии дают ему знания, помощников и проверки, но не готовые рецепты.

Голос и картинки вы подключаете свои: OpenAI, ElevenLabs (в том числе свой клонированный голос),
Google Gemini или любую свою программу, например Kimi-Audio, Piper, Silero или ComfyUI. Можно не
подключать ничего: тогда получится ролик без голоса и без сгенерированных картинок, на музыке,
тексте, графике кодом и 3D из Blender.

## Что получается

Жанры, которые студия делает сегодня (примеры брифов лежат в [`examples/briefs/`](examples/briefs)):

- **Промо малого бизнеса.** Кофейня, мастерская, салон: предложение, цена, срок, адрес и
  призыв прийти. Режиссёр следит, чтобы цифры на экране совпадали с брифом.
- **Детская сказка.** Бумажная аппликация, войлок, мягкий ночной свет, спокойный темп без
  вспышек.
- **Объяснялка.** Карточки, схемы, макеты экранов приложения, понятие за 30 секунд.
- **Список или отсчёт.** «5 ошибок…», «3 способа…»: крупные цифры, живая типографика.
- **Анонс события.** Дата, место и вход крупно, кинетическая типографика, яркая палитра.
- **3D-предмет.** Товар, смоделированный в Blender: студийный свет, облёт камеры, смена
  режимов как смена времени суток.
- А ещё графики и цифры как часть рассказа, погода и время суток в сцене, 2.5D-параллакс из
  фото заказчика, «экран ноутбука» для демонстрации продукта.

Каждый ролик режиссёр делает по-своему: студия запоминает облик последних роликов и не
повторяет один и тот же шрифт и палитру.

## Быстрый старт

Нужны macOS (основная платформа) или Linux, Node 22+ (проверено на 24), ffmpeg и
[Claude Code](https://claude.com/claude-code) с подпиской Claude Pro или Max.

```bash
brew install node ffmpeg                       # 1. Linux: nodejs 22+ и ffmpeg из своего менеджера пакетов
git clone https://github.com/<owner>/ai-video-studio && cd ai-video-studio   # 2.
npm run setup                                  # 3. пакеты, проверка программ, .env, модель whisper, doctor
claude                                         # 4. войдите своей подпиской и скажите: «сделай ролик по examples/briefs/01-coffee-promo.md»
npm run make -- --brief examples/briefs/05-event.md   # 5. или целиком без окна: итог в jobs/<slug>/out/final.mp4
```

По желанию: `brew install --cask blender` для 3D-ассетов, `brew install whisper-cpp` для точных
таймингов слов в субтитрах. `npm run setup` предложит скачать модель whisper (около 0,5 ГБ,
бесплатно).

## Как работать

### Как скилл, в сессии Claude Code

Запустите `claude` в корне репозитория и попросите обычными словами: «сделай рилс для
цветочного магазина про пять ошибок в уходе», «поправь финал в последнем ролике». Сработает
скилл [`make-video`](.claude/skills/make-video/SKILL.md). Он соберёт бриф из просьбы, заведёт
папку ролика и запустит режиссёра в одном из двух режимов.

- **«Сам»** (по умолчанию). Режиссёр работает без окна, в фоне, два этапа с чистым контекстом:
  сборка и доводка. Вы получаете файл, концепт одной фразой, время, стоимость и «Вопросы
  заказчику».
- **«Вместе»**. Скажите «давай вместе» или «покажи концепты». Тогда режиссёром становится сама
  сессия: показывает три направления на выбор, лист кадров, итог проверок. В этом же режиме
  удобно править готовый ролик.

### Одной командой

```bash
npm run make -- --brief brief.md          # или --brief "текст брифа"
```

| Флаг | Что делает |
|---|---|
| `--slug имя` | имя папки ролика (`jobs/<slug>/`) |
| `--brand папка` | материалы заказчика: `logo.svg/png`, `photos/`, `refs/`, `brand.json` (`{colors, fonts, words: {use, avoid}}`) |
| `--author "@handle"` | подпись в финале |
| `--size 1080x1920`, `--fps 30` | формат |
| `--model`, `--effort` | модель и усилие режиссёра (по умолчанию модель Claude Code для вашего аккаунта; личные настройки из `~/.claude` режиссёр не читает) |
| `--max-budget-usd 6` | жёсткий потолок на весь прогон в пересчёте на цены API |
| `--resume` | продолжить прерванный прогон в той же папке |
| `--dry-run` | только создать папку ролика |

В папке ролика остаются `out/final.mp4`, `notes.md` (решения режиссёра, что проверено, «Вопросы
заказчику»), `director.log` и `director.result.json` (время, ходы, стоимость). Если режиссёр не
закрыл важные замечания, вместо `final.mp4` будет `out/candidate.mp4` со статусом
`needs-stage-2`. Продолжить можно через `--resume`.

### Вручную или с Codex

```bash
studio/bin/studio new kofeinya --brief brief.md
cd jobs/kofeinya && PATH="$PWD/../../studio/bin:$PATH" claude    # или codex
```

В папке ролика уже лежат `CLAUDE.md` и `AGENTS.md` (руководство режиссёра) и `.claude/skills/`
(все скиллы). Инструменты перечислены в `studio help`. Для Codex порядок описан в
[`AGENTS.md`](AGENTS.md).

## Провайдеры

Все настройки хранятся в `.env`. Файл в `.gitignore`, образец с комментариями лежит в
[`.env.example`](.env.example). Что подключено и что режиссёр сможет сделать, покажет
`npm run doctor`.

| Шаг | Переменная | Варианты | Без него |
|---|---|---|---|
| Озвучка | `VOICE_PROVIDER` | `openai` · `elevenlabs` · `command` · `none` | ролик на музыке и тексте на экране |
| Картинки | `IMAGE_PROVIDER` | `openai` · `gemini` · `command` · `none` | графика кодом, бумага, 3D, ваши фото |
| Тайминги слов | `ASR_PROVIDER` | `auto` · `whisper` · `openai` · `none` | оценка по длине слов, с предупреждением |

| Провайдер | Что умеет | Ключи в `.env` |
|---|---|---|
| OpenAI TTS | указания диктору (`--style`), 13 голосов | `OPENAI_API_KEY`, `OPENAI_TTS_MODEL`, `OPENAI_TTS_VOICE` |
| ElevenLabs | свой клонированный голос, тайминги слов вместе с аудио | `ELEVENLABS_API_KEY`, `ELEVENLABS_VOICE_ID`, `ELEVENLABS_MODEL` |
| OpenAI Images | прозрачный фон, референсы `--ref` | `OPENAI_API_KEY`, `OPENAI_IMAGE_MODEL` |
| Google Gemini | референсы; прозрачности нет (фон убирает `IMAGE_BG_COMMAND`, например rembg) | `GEMINI_API_KEY`, `GEMINI_IMAGE_MODEL` |
| `command` | любая ваша программа озвучки или картинок | `VOICE_COMMAND`, `IMAGE_COMMAND` |

### Свой голос в ElevenLabs

1. В ElevenLabs откройте Voices → Add voice → Instant или Professional Voice Clone и запишите
   образец своего голоса.
2. Скопируйте Voice ID нового голоса.
3. Впишите в `.env`:

```bash
VOICE_PROVIDER=elevenlabs
ELEVENLABS_API_KEY=ваш_ключ
ELEVENLABS_VOICE_ID=id_вашего_голоса
ELEVENLABS_MODEL=eleven_multilingual_v2
```

Тайминги слов ElevenLabs отдаёт вместе с аудио, whisper для субтитров не нужен.

### Kimi-Audio, Piper или любая своя модель (`command`)

Студия вызывает вашу команду и подставляет в неё пути. Текст реплики передаётся только файлом,
поэтому кавычки и спецсимволы не ломают команду.

| Подстановка | Что это |
|---|---|
| `{text_file}` | файл с текстом реплики (UTF-8) |
| `{out_wav}` | куда записать аудио (wav, mp3 или любой формат ffmpeg) |
| `{voice}`, `{lang}` | голос и язык (`ru` по умолчанию) |
| `{style_file}` | указания диктору, может быть пустым |
| `{words_json}` | необязательно: запишите сюда `[{"text","start","end"}]` в секундах, тогда ASR не нужен |

```bash
VOICE_PROVIDER=command
VOICE_COMMAND=python3 ~/tts/kimi_tts.py --text-file {text_file} --out {out_wav}
# Piper:   VOICE_COMMAND=piper --model ~/piper/ru_RU-irina-medium.onnx --output_file {out_wav} < {text_file}
# macOS:   VOICE_COMMAND=say -v Milena -f {text_file} -o {out_wav} --data-format=LEI16@22050
```

Обёртка для Kimi-Audio или другой модели — это обычный скрипт: прочитать текст из
`--text-file`, синтезировать речь своей моделью, записать wav в `--out`. Примерно так:

```python
# ~/tts/kimi_tts.py: шаблон обёртки, синтез замените вызовом своей модели
import argparse, soundfile as sf
p = argparse.ArgumentParser(); p.add_argument("--text-file"); p.add_argument("--out")
a = p.parse_args()
text = open(a.text_file, encoding="utf-8").read()
audio, sr = synthesize(text)      # ваша модель: Kimi-Audio, XTTS, F5-TTS, Silero…
sf.write(a.out, audio, sr)
```

Картинки подключаются так же, через `IMAGE_COMMAND` с подстановками `{prompt_file}`
`{out_png}` `{width}` `{height}` `{refs}`. Подходит ComfyUI, Stable Diffusion или свой сервер.

Платные запросы кэшируются в `.cache/` по провайдеру, модели, голосу и тексту, поэтому повтор
того же запроса бесплатен. Сбои сети и ответы 429 и 5xx студия повторяет с паузой.

## Как это устроено

```
бриф → doctor (что подключено) → факты брифа → три концепта → стиль (theme.json)
     → голос → биты по словам → ассеты (картинки, Blender) → сцены Remotion
     → check и кадры → review.ts (проверки) → критик со свежим взглядом
     → рендер с воротами → probe → notes.md и «Вопросы заказчику»
```

- **Режиссёр** — Claude Code. Руководство (`studio/CLAUDE.md`) задаёт планку: ролик смотрят на
  телефоне в ленте, ничего не уезжает за край, текст читается, нет рывков и пустых кадров.
  Как этого достичь, режиссёр решает сам.
- **Инструменты** (`studio/bin`, вызов `studio <инструмент>`): `doctor`, `voice`, `image`,
  `blender`, `still`, `sheet`, `render`, `probe`, `check`, `looks`, `sfx`, `music`, `fonts`,
  `facts`, `skill`, `api`.
- **Проверки.** `studio check` ловит недетерминизм, `review.ts` смотрит черновик: вылеты за
  край, контраст, размер текста, рывки камеры, совпадение цифр с речью. Критик-субагент видит
  только бриф и плитки «как в ленте», без истории сборки. Финал не выпускается, пока не закрыты
  главные замечания.
- **Скиллы** (`studio/skills`, карточка: `studio skill <имя>`):

| Направление | Скиллы |
|---|---|
| Режиссура | `art-direction` (стиль-библия), `beat-planner` (раскадровка от звука), `transitions` (монтаж без «вжухов»), `sound-design` (музыка, атмосфера, сведение) |
| Правда | `claims-and-compliance` (факты брифа, утверждения, регулируемые категории, вопросы заказчику) |
| 2D | `kinetic-typography`, `paper-2d`, `explainer-cards`, `data-viz`, `generated-imagery`, `fx-particles`, `presentation-frame` |
| 3D | `blender-asset-factory`, `object-scene-3d`, `typography-3d`, `materials`, `scene-state` |
| Качество | `camera-choreography`, `layout-guard`, `self-review` |

## Сколько стоит и сколько ждать

- **Режиссёр:** один ролик — примерно **$2–4** в пересчёте на цены API и **10–20 минут** на Mac
  с Apple Silicon (по нашим прогонам). На подписке Claude это расход лимита использования, а не
  отдельный счёт. На Pro лимита окна может хватить на один–два ролика, для регулярной работы
  удобнее Max. Потолок прогона задаёт `--max-budget-usd` (по умолчанию 6).
- **Внимание:** если в окружении задан `ANTHROPIC_API_KEY`, Claude Code списывает работу с
  API-счёта, а не с подписки. Запуск предупредит об этом.
- **Голос и картинки** оплачиваются вашими ключами по тарифам провайдеров. Обычно это до 12
  картинок и несколько реплик на ролик, повторы бесплатны благодаря кэшу. С `command` и `none`
  они ничего не стоят.
- **Рендер, звуки, музыка, Blender, whisper** работают локально и бесплатно.

## Ограничения

- Студия заточена под русский язык: шрифты с кириллицей, озвучка по умолчанию `ru`. Другие
  языки работают (`--lang`, `"lang"` в `lines.json`), но проверены меньше.
- Формат: короткие ролики примерно до 60 секунд, по умолчанию вертикальные 1080×1920.
- Видео, музыку и 3D по картинке студия не генерирует. Движение собирается кодом и в Blender,
  музыка берётся из CC0-каталога.
- Режиссёр — ИИ. Он проверяет себя, но перед публикацией ролик и «Вопросы заказчику» нужно
  посмотреть глазами.
- Основная платформа — macOS. Linux должен работать, но проверен меньше. Windows не
  поддерживается (можно попробовать WSL2).
- Запуск одной командой рассчитан на Claude Code. С Codex и другими агентами ролик делается в
  интерактивной сессии по `AGENTS.md`.
- Первый рендер скачивает Chrome Headless Shell для Remotion. `npm run setup` делает это
  заранее.

## Безопасность и ответственность

- В репозитории нет ключей и чужих данных. Ваши ключи живут только в `.env`, который не попадает
  в git. Инструменты студии читают его сами и никогда не печатают ключи. Режиссёру ключи не
  передаются, а читать `.env` ему запрещено правилами запуска.
- Ролики (`jobs/`) и кэш (`.cache/`) тоже в `.gitignore`.
- За содержание и публикацию ролика отвечаете вы. Режиссёр не выдумывает цифры и обещания и
  выносит допущения в «Вопросы заказчику», но проверять их нужно вам.
- Клонируйте только свой голос или голос человека, давшего на это согласие. Чужие логотипы,
  бренды и реальных людей без согласия не используйте.
- Реклама в регулируемых категориях (медицина, БАД, финансы, алкоголь, дети) ведётся по скиллу
  `claims-and-compliance`: он подсказывает обязательные пометки по 38-ФЗ «О рекламе» и
  напоминает о маркировке рекламы (erid). Это ориентир, а не юридическая консультация.

## Структура

```
.claude/skills/make-video/   скилл для Claude Code: «сделай ролик…»
studio/CLAUDE.md             руководство режиссёра (в папке ролика это CLAUDE.md и AGENTS.md)
studio/bin/                  инструменты студии (studio <инструмент>), провайдеры, make-обвязка
studio/lib/                  библиотека сцен @studio: кадр, движение, шрифты, 3D, бумага
studio/skills/               20 скиллов: знания, помощники, проверки
studio/template/             шаблон папки ролика
studio/make.ts               запуск режиссёра без окна (npm run make)
scripts/setup.mjs            npm run setup
public/sfx, public/music     звуки и музыка CC0
examples/briefs/             примеры брифов
tests/                       тесты студии (npm test)
```

Разработка: `npm run typecheck && npm test`. Улучшения руководства и скиллов приветствуются.
Режиссёр сам пишет предложения в `notes.md` каждого ролика, и это хороший источник идей.
