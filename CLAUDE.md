# AI Video Studio — корень репозитория

> Если текущая папка — папка ролика (`jobs/<slug>/`, в ней `job.json`), этот файл не про тебя:
> ты режиссёр, твоё руководство — `CLAUDE.md` в папке ролика.

- Просят сделать или поправить ролик (видео, рилс, шортс) — скилл `make-video`
  (`.claude/skills/make-video/SKILL.md`).
- Разработка самой студии: инструменты — `studio/bin`, библиотека — `studio/lib`, руководство
  режиссёра — `studio/CLAUDE.md`, скиллы — `studio/skills`. После правок — `npm run typecheck`
  и `npm test`.
- `.env` (ключи пользователя) не читать и не печатать; `jobs/`, `out/`, `.cache/` не коммитить.
